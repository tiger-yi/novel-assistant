# 第 136 章 缝合之隙

“罪民张启明……大逆不道……当诛……”

金属刮擦的滞涩音节在逼仄的管道内荡开。半空中，那张散发着浓烈死气的明黄圣旨无风自动，纸面鼓胀。

圣旨中央沁出一个诛字。

管道内的气流瞬间被抽空。无形的重压从头顶直贯而下，死死压在张启明双肩。

咔咔。

张启明双膝不可遏制地弯折。体内刚刚缝合的紫电雷骨相互挤压，骨缝间爆出令人牙酸的脆响。他死死咬住牙关，额头血管突突直跳。顺着嘴角淌下的血丝还未滴落，便被重压生生碾成血雾。

他在心底敕一字：顶。

识海深处，残破的阳平治都功印猛地一震，泼洒出纯正金辉，死死抵住灵台。丹田处的阴阳磨盘疯狂转动，生生绞碎顺着毛孔侵入经脉的律法死气。

他双手撑住膝盖，脊梁骨一寸、一寸，硬生生顶着威压撑直。

对面，庞大的肉山向前倾轧。铜根镇守使幽绿的眼眶周围，腐肉疯狂蠕动。它抬起那条由青铜活塞与肿胀腐肉粗暴缝合的右臂。腥风扑面。巨拳带着撕裂空气的爆音，直奔张启明头顶砸落。

劲风刮面如刀。张启明没有退，眼睛死死盯着那条挥动的巨臂。

刺啦——

极其刺耳的摩擦声。青铜齿轮与包裹它的血肉之间，迸出几点细碎的火星。黑色的黏液顺着缝隙被生生挤了出来。齿轮咬合处，出现了半息不到的卡顿。

排异。

张启明眼底寒光骤聚。脚下九幽步踏出，鞋底在脚下那层恶臭的肉毯上犁出一道深沟。他整个人如同一抹灰影，贴着管壁滑出三丈。

轰！

巨拳砸中青铜管壁。整个地下管道剧烈颠簸。大块大块的腐肉混着青铜碎屑簌簌砸落。管壁硬生生凹陷下去一个半丈宽的浅坑。

身躯过于庞大，管道又极度逼仄。这一拳落空，镇守使沉重的身躯陷入了短暂的僵直。

张启明抹掉下巴上的血迹，胸膛剧烈起伏。

远古道门遗留的辟邪青铜，被祭祀监用大武律法和畸变腐肉强行缝合。青铜齿轮本能地排斥外层血肉。维系这具肉山不崩塌的，只有胸口那颗疯狂泵血的黑心，以及手里那张强行镇压的圣旨。

不用去碰圣旨。

张启明深吸入一口浑浊的空气。阴阳磨盘停止吞噬周围的煞气，体内残存的最后一丝精纯灵机，全数逼向右手食指。

指尖皮肉裂开。一滴青蓝水雷挤出指尖。

没有爆裂的电光。只有极其纯粹的青蓝，水滴般浑圆。

吼——

镇守使胸腔的黑心跳动骤然暴涨。它强行扭转庞大的身躯，左侧布满骨刺的肉爪贴着地面横扫而至。

张启明猛地伏低身子，脊背几乎擦着扫过的骨刺。骨刺带起的腥风割破了他的衣袍，在背上留下一道血痕。

他双腿肌肉猛然膨胀，爆发。整个人贴着肉毯，如同贴地飞行的利箭，直插镇守使庞大的腹部。

腹部中央，腐肉被撑开一道裂隙。一组巨大的青铜齿轮半露在外，正艰难地绞动着黏稠的血肉。

张启明在心底敕字：醒。

手中残剑顺着腐肉裂隙，极其精准地掼入齿轮轴心。

指尖那滴青蓝水雷顺着剑身，没入远古机械深处。

嗡——

不是剑鸣。是极其宏大的金属共振。沾满黑色污血的青铜齿轮表面，瞬间亮起密密麻麻的道门符文。齿轮转速在半息内飙升十倍。

呃啊啊啊——

镇守使发出极其凄厉的嘶嚎。机械卡死的酸牙声与血肉撕裂声混杂在一起。

苏醒的远古齿轮不再受大武律法压制，开始疯狂逆向绞杀。缝合在机械表面的腐肉被生生绞成肉泥。大股黑血和腥臭的黄油从它的七窍、关节处喷涌而出。

明黄圣旨剧烈震颤，爆发出刺目的黄光，试图重新镇压反叛的机械。

晚了。

随着腹部血肉大面积崩塌。胸腔正中，那颗磨盘大小的漆黑心脏，彻底暴露在空气中。

张启明拔出残剑。借着齿轮崩解掀起的气浪，双膝微屈，猛地弹射而起。

双手死死握紧剑柄。体内最后的余力压榨一空。

剑锋化作一抹惨白的流光。

噗嗤。

剑刃毫无阻滞地贯穿漆黑心脏。

黑血如高压水柱般喷射，糊了张启明满脸。心脏深处的浓郁死气顺着剑身疯狂倒灌，试图钻入手心。

张启明直接松开剑柄，右脚在庞大的肉山上重重一蹬，身形向后暴退。

心脏内部的压力彻底失衡。

砰——！！

沉闷的巨响在管道内炸开。磨盘大小的黑心像撑爆的皮筏般炸得粉碎。气浪夹杂着碎肉与金属破片，在逼仄的空间里形成恐怖的绞杀风暴。

张启明被气浪掀飞，狠狠撞上后方的管壁。喉头一甜，喷出一大口鲜血。

在漫天飞溅的污血中，一枚鸽子蛋大小、散发着柔和青光的青铜核心从炸裂的心脏处崩飞出来。

他左手猛地探出，死死将其攥在掌心。青铜的冰凉触感瞬间传遍全身。

镇守使庞大如山的躯体彻底失去支撑，轰然垮塌。破碎的废铜烂铁与烂肉堆积成山，将上方的管道死死堵住。

心脏炸裂的恐怖冲击波沿着错综复杂的铜根网络疯狂蔓延。头顶上方极高处，传来一连串沉闷的轰鸣。远古枢纽的自毁机制被彻底引爆，传承大殿所在的地宫开始大面积坍塌。

大块的青铜穹顶和岩石砸落。

张启明顺着湿滑陡峭的管道，向着深不见底的黑暗急速滑落。他猛地抬起头，透过上方不断坠落的碎石，隐约看到一抹即将被彻底掩埋的幽蓝光晕。

那是老乞丐燃烧残躯撑起的无舌铃结界。

他咬紧牙关，任由呼啸的风声淹没一切。失重感传来，管道的倾斜角度越来越大，最后几乎变成了垂直的深渊。

砰！砰！

他无法控制下落的速度，后背和双肩接连撞击在坚硬的青铜管壁上。刚刚愈合的伤口再次崩裂，温热的鲜血迅速浸透了残破的衣袍。

他强忍着五脏六腑移位般的剧痛，双手死死抱住头部，将体内仅剩的一丝雷罡逼向后背，形成一层微弱的电芒护盾。

咔嚓——

残破的阳平治都功印在识海中发出微弱的嗡鸣，护住他最后一点灵台清明。

极速坠落中，周围浓郁的煞气逐渐变淡。取而代之的，是一股极其古老、刺骨的阴冷水汽。这水汽中没有大武帝国那种令人作呕的腐臭味，反而带着一种深埋地下千万年的死寂。

黑暗深处，隐隐传来湍急的水流声。

扑通！

冰冷刺骨的水流瞬间淹没了他的头顶。巨大的冲击力拍击在他的胸口，将他肺里最后一口浊气强行挤了出去。

水流极其湍急，卷着他在黑暗的地下暗河中翻滚。张启明死死咬住牙关，左手依然死死攥着那枚散发着柔和青光的青铜核心。

冰冷的水流顺着他身上的伤口疯狂倒灌，带走他体温的同时，也洗刷掉了他身上残留的镇守使污血。

他屏住呼吸，任由暗河的水流将自己带向未知的前方。

不知道过了多久，水流逐渐变得平缓。

张启明的后背擦过一片长满青苔的坚硬河床。他猛地睁开眼，双腿在水底用力一蹬，整个人破水而出。

哗啦。

他趴在一块湿滑的岩石上，剧烈地咳嗽着，大口大口地贪婪呼吸着冰冷潮湿的空气。

他抹去脸上的水渍，借着左手那枚青铜核心散发的微弱青光，打量着四周。

这里是一个巨大的地下溶洞。头顶是倒悬的钟乳石，脚下是奔腾不息的黑色暗河。水汽弥漫，遮蔽了视线。

他成功脱离了大武祭祀监的视线，真正深入了远古道门遗迹的最底层。
