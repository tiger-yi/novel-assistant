## 1. 卷一：荒村雷鸣 (1-10章) —— 诡道开端

- **[元年/正月] - [天师重生] - [张启明 16岁/淬体境初期]**
    - 张启明重生于青州黑水村，全村被屠，初次觉醒观想法，击退诡影残余。
    - 获得关键道具：玄铁桃木剑。

- **[元年/正月] - [雷霆洗练] - [张启明 16岁/淬体境中期]**
    - 于黑水村宗祠吞噬尸狗妖晶，利用雷法观想净化煞气，突破至淬体境中期。
    - 发现胸口“祭”字印记，推测黑水村为“养殖场”。

- **[元年/二月] - [寿宴惊雷] - [张启明 16岁/淬体境后期]**
    - 县令寿宴爆发，朱大善人反水，白莲教突袭。
    - 张启明以破障雷锥强行破阵，入地牢斩杀异化县令（熔脉后期），救出小翠。
    - 平安县衙覆灭，全城陷入混乱。

- **[元年/二月] - [因果剥离] - [张启明 16岁/极度虚弱]**
    - 张启明带小翠逃至城郊龙王庙，发现灵童夺舍。
    - 以心头血画雷符，将“灵童”封印入镇魂石，剥离小翠因果。

## 2. 卷二：长生诡事 (11-60章) —— 逃亡与成长

- **[元年/二月] - [雷火洗地] - [张启明 16岁/极度虚弱]**
    - 张启明利用“长生神像”作为引雷点，强行转化体内煞气为纯阳雷罡，引动九天玄雷。
    - 斩获：击杀影卫统领（熔脉境），夺取【长生种·真晶】。
    - 发现：证实荒村为朝廷秘密实验场。

- **[元年/二月] - [雷火焚穴] - [张启明 16岁/神魂受创]**
    - 于阴平山活死人墓引爆高位格雷种，击杀白莲教白祭司及所有影卫精锐。
    - 夺取道门法铃（2阶）。张启明神魂受震荡，陷入昏迷。

- **[元年/二月] - [真火炼骨] - [张启明 16岁/紫电雷骨]**
    - 利用“阳燧真火”与“虎符兵煞”三重锻打，肉身极境突破，彻底抹除因果痕迹。

- **[元年/三月] - [诡市风云] - [张启明 16岁/熔脉初成]**
    - 抵达阴平山外围“诡市”，反杀“青州三鬼”立威。
    - 突破：借助“九天雷脉”彻底冲破瓶颈，晋升熔脉境。

- [元年/三月] - [医馆惊变] - [张启明 16岁/熔脉极境]
    - **第38章**: 张启明带林月儿和小翠抵达青州边城。强闯“回春医馆”，直面觊觎其雷骨的白神医。
    - **第39章**: 展现“熔脉境极境”力量，踩爆白神医头颅，肃清医馆。发现“食堂”菜单及信物，确认城主李文正及当地豪强均深陷“食人”链条，林月儿已被标记为“灵童祭品”。获取“安魂散”并给小翠服用，压制其体内诡异侵蚀。

- [元年/三月] - [宴无好宴] - [张启明 16岁/熔脉极境]
    - **第40章**: 张启明带林月儿以特使身份潜入城主府夜宴。见证了披着文明外衣的食人魔窟，正面硬刚城主李文正。
    - **第41章**: 于城主府夜宴掀桌，施展九天神雷正面击杀城主李文正（披甲境初期）。夺取墨玉印信。城主府权贵因失去压制而集体异化，全城陷入大乱。
    - **第42章**: 张启明施展位格转嫁金蝉脱壳，引开银面执法官投影，带林月儿逃入红雾荒原。

- **[元年/三月] - [荒原夜奔] - [张启明 16岁/熔脉极境 (极度虚弱)]**
    - **第43章**: 张启明携林月儿穿过红雾荒原，遭遇“红绸猎手”并将其击杀。
    - **发现**: 利用猎手核心晶体穿透红雾，寻获“界河古道”。
    - **危机**: 遭遇“银面执法官”神识横扫，施法强行封禁生机躲避。

- **[元年/三月] - [黑水古渡] - [张启明 16岁/阴煞入骨(极度虚弱)]**
    - **第44章**: 抵达界河古渡。张启明以雷火净化“血煞丹”救活林月儿。面对银面执法官投影追击，利用“位格转嫁”将祭祀监印记强行钉入江中浮尸。
    - **冲突**: 引发银面执法官投影与江底沉睡的“蛟骸”（钉有龙虎金印）爆发冲突。
    - **代价**: 左腿经脉被红雾阴煞侵蚀严重，雷脉透支。
    - **获得**: 借助乱局逃离，登上顺流而下的运棺船（第45章展开）。

- **[元年/三月] - [孤舟南下] - [张启明 16岁/神魂受损(极度虚弱)]**
    - **第45章**: 登上诡异运棺船。利用界河煞气强行洗去‘祭’字印记，神魂红光消散，但也导致左腿被阴煞严重侵蚀。在船上发现‘七星钉魂阵’与贡品，暂时脱离银面执法官视线。
- **[元年/三月] - [古渡疑云] - [张启明 16岁/雷脉近枯]**
    - **第46章**: 抵达界河古渡口遭遇林家统领林大勇截杀。斩杀已异化为“细犬”形态的林大勇。搜获“祭祀监密信”，揭露青州大祭与林月儿及张家遗物的关联。

- **[元年/三月] - [雷火焚江] - [张启明 16岁/熔脉极境]**
    - **第47章**: 面对界河封锁，张启明引爆“龙虎山孽徒”留下的地脉残碑（敕令断流），引发界河断流与地脉殉爆，彻底摧毁祭祀监拦江尸阵。
    - **代价**: 脏腑受损严重，咳血不止，肉身处于极度虚弱态。
    - **因果**: 首次通过“雷罡灵线”回收法器，摆脱了银面执法官的直接锁定，逃入云雾泽。

- **[元年/三月] - [云深古刹] - [张启明 16岁/神识虚弱]**
    - **第48-49章**: 带林月儿逃入云雾泽，在泽中发现被遗忘的道门古庙“云深观”。神像泣血，唤醒残留道门先贤理智。

- **[元年/三月] - [泽中惊雷] - [张启明 16岁/雷脉重塑(极度虚弱)]**
    - **第50章**: 张启明在云深观遭遇银面执法官投影。引爆云雾泽积攒万年的尸腐邪气，制造连锁雷爆清场。摧毁投影，道门法铃彻底碎裂，但也助其破而后立重塑雷脉。

- **[元年/三月] - [白骨官道] - [张启明 16岁/雷脉初塑(虚弱)]**
    - **第51章**: 张启明经由白骨官道抵达青州府，与神秘“收尸人”达成交易，以‘雷击木’碎片换取‘收尸杂役’身份入城牒。成功潜入青州府城。
    - **第52章**: 伪装成杂役阿四混入青州内城，目睹青州大祭坛（白骨堆砌、血眼悬空）。发现林震南（被废）与林月儿（被囚）踪迹，并在马车中窥见疑似龙虎山道袍的神秘人。

- **[元年/三月] - [贫民余烬] - [张启明 16岁/雷脉修复中(重伤)]**
    - **第56-57章**: 张启明在收尸人的贫民窟石室苏醒并疗伤。利用“阳平治都功印”降维破译祭祀监密信。
    - **第58章**: 张启明化身收尸杂役，利用“位格转嫁”引爆赵家与白莲教在祭坛周边的冲突，成功潜入贫民窟深处水窖地眼。
    - **发现**: 揭示林月儿不仅是祭品，更是开启某处龙虎山遗迹的“钥匙”，朝廷意图夺取“太一雷浆”修成“雷劫不灭体”。
    - **成果**: 毁去密信，筹谋在三日后的青州大祭中反击。

- **[元年/三月] - [万里孤行] - [张启明 16岁/脏腑重伤(极度虚弱)]**
    - **第59-60章**: 离开青州府城五日后。张启明在前往京师的官道驿站识破“人肉包子”黑店，以指尖雷芒瞬杀剥皮匠下属。夺取【剥皮匠铜牌（肆/伍）】，得知京师官道尽头有“剥皮窑”。

## 3. 卷三：归墟路 (61-?章) —— 归墟

- **[元年/三月] - [官道截杀] - [张启明 16岁/熔脉极境(重伤)]**
    - **第61章**: 雨夜官道遭影卫截杀。以铜牌肆、伍转嫁因果，误导血引令指向剥皮窑方向；一字“止”以阳平印冻结官道半息，击毁细犬嗅觉节点，脱身北上。

- **[元年/三月] - [深宫锁龙] - [张启明 16岁/熔脉极境(重伤)]**
    - **第62章**: 借剥皮窑动乱之机抵达京师外郭，沿御沟暗渠潜入祭祀监外围“锁龙井”，目击绯袍内侍以“活丹”投喂井下“龙脉”。发现龙虎山旧锁之“扣”线索。

- **[元年/三月] - [剪线落扣] - [张启明 16岁/熔脉极境(重伤)]**
    - **第62-63章**: 借剥皮窑动乱之机抵达京师外郭，沿御沟暗渠潜入祭祀监外围“锁龙井”。剪断官道因果网，将其钉入井扣，造成追踪链路30%缺失。

- **[元年/三月] - [盲点深渊] - [张启明 16岁/沉眠(雷骨重塑中)]**
    - **第71-73章**: 龙虎山传承殿归墟归来，张启明陷入深度沉眠（第3天）。
    - **变数**: 太一雷浆与神将须根交织，【雷骨金纹】初步显化。京师贫民窟废墟中，老乞丐手中“无舌铃”自鸣，唤醒潜伏旧部。
    - **现状**: 京师锁龙井处于“因果真空期”，银面首领调集嗅灵犬展开地毯式搜捕。
    - **第63章**: 以阳平治都功印配合雷击木缝针三落，将“官道锁定”余线剪入井扣，彻底摆脱追踪压力。

- **[元年/三月] - [遁走四海] - [张启明 16岁/熔脉极境(生出水雷意境初胚)]**
    - **第64章**: 奔袭抵达东南沿海天水关，引动海气共鸣施展“雷降”摧毁追兵，望见归墟虚影。

- **[元年/三月] - [归墟之门] - [张启明 16岁/熔脉极境(重伤)]**
    - **第65章**: 驾孤舟深入归墟，以阳平印位格压制畸变巨兽。抵达万丈青铜大门，点燃雷纹印记，门缝开启，被光雨吞没进入归墟禁地。

- **[元年/三月] - [神识化灵] - [张启明 16岁/出神境初期(极度虚弱)]**
    - **第66章**: 进入归虚廊桥，遭遇5阶位格神魂吞噬者。强行开启阴阳磨盘炼化神魂黑影（伏笔G），神识化灵，晋升观想3阶：出神。以阳平印位格唤醒廊桥万灯；万灯处于“照明/镇邪”态，需印位格持续维持，周边低位格诡异暂清、高阶潜伏。状态：灵力几近枯竭（约1%），神魂旧伤趋稳。

- **[元年/三月] - [远古传承] - [张启明 16岁/出神境初期(重伤)]**
    - **第67章**: 于归墟传承殿剥落因果涂抹，启开青铜匣室，得一枚“道种”（封存/未觉醒）。未强炼，以月白绸缎残片封存随身。确认廊桥尽头钟声为法器残响，维持最低秩序。状态：脏腑疼痛短期加重；阳平印位格仍处静默期；神识外放需谨慎。
    
- **[元年/三月] - [重塑真身] - [张启明 16岁/出神境初期(重伤趋稳)]**
    - **第68章**: 借钟律引出一缕“太一雷浆”，以月白绸缎为载导入雷骨与脏腑破损处；承受三组劫火重压（九声/三组），未强炼道种，仅行润泽。状态：神识稳定度提升，旧伤由撕裂降为钝痛，行动力提升约20%；阳平印仍处静默期。
    
- **[元年/三月] - [道门重光·前奏] - [张启明 16岁/出神境初期(稳态)]**
    - **第69章**: 于归墟廊桥尽头试探钟残，与灯海亮度曲线短升后回落；影壁涂抹因果层剥落，显露修复序列“印、钟、浆、种”。记录“钟道碎齿”缺件线索；不强行唤印。状态：神识稳态，小幅提升行动力；太一雷浆仍入骨封存；阳平印需后续充能。
    
- **[元年/三月] - [众神归位] - [张启明 16岁/出神境初期(严重透支)]**
    - **第 71 章**: 潜入京师锁龙井核心，以太一雷浆激活道种，唤醒道门远古神将虚影，降下汞态雷光洗礼全城。
    - **成果**: 彻底摧毁锁龙井祭坛及周边白骨祭台，大武祭祀监因果网出现30%缺失，银面执法官本体受创喷出黑血。
    - **代价**: 张启明灵力剩余不足1%，神识因规则共鸣严重透支，需进入长达七日的深度沉睡；经脉微细裂纹，脏腑重伤。

- **[元年/三月] - [沉眠与裂痕] - [张启明 16岁/出神境初期(沉睡中)]**
    - **第 72 章**: 京师锁龙井祭坛崩毁，因果网缺失30%，银面执法官本体受创。张启明进入深度沉眠，灵力缓慢恢复。

- **[元年/三月] - [盲点与铃音] - [张启明 16岁/出神境初期(沉睡第3天)]**
    - **第 73 章**: 沉眠第3天，灵力恢复至3%。雷骨生出金色纹路，识海中神将“须根”扎入，太一雷浆化为经脉溪流。银面搜捕无果，旧部老乞丐摇铃响应。
    - **状态**: 重伤恢复中，雷骨强度提升，脏腑钝痛缓解。

- [元年/三月] - [嗅灵之灾] - [张启明 16岁/沉眠第4天 (雷骨金纹30%)]
    - **第74章**: 祭祀监银面执法官携三头“嗅灵犬”搜捕至城隍庙。张启明处于深度沉眠，体内雷骨金纹进化至30%，产生规则层面的被动反击位格。嗅灵犬触碰张启明瞬间被金雷碳化，损毁1头。银面执法官遭位格反噬撤退。城隍庙周边形成“因果真空区”。

- **[元年/三月] - [醒转与夺路] - [张启明 16岁/出神境初期(重伤稳态/短醒)]**
    - **第75章**: 城隍庙醒转，以“崩劲·雷落指”击毁嗅节点，借旧部“铃音”引路脱身；再损嗅灵犬一头；银面执法官受位格与环境压制短退。
    - **状态**: 行动力小幅提升；阳平印仍静默需充能；雷骨金纹运行稳定度微升；不动用消耗品。

- **[元年/三月] - [破庙重逢] - [张启明 16岁/出神境初期(重伤稳态/短醒)]**
    - **第76章**: 破庙与老乞丐会合，铃音引路构建百丈干扰区；处置门梁嗅节点；识别仿冒月白绸缎信号，门槛涟漪线截断退敌。
    - **状态**: 行动力小幅提升；阳平印静默；未动用消耗品；疑有内线潜伏。
    
- [元年/三月] - [祭祀监之怒，暗流汹涌] - [张启明 16岁/出神境初期(重伤稳态/恢复30%)]
    - **第77章**: 时间已过三更。银面首领下达封城令，嗅灵犬重启“嗅脉阵”。张启明与老乞丐以“铃为轴、暗渠为载”布因果小径，执行“绣针三落”（门槛/巷口/井眼）剪断嗅脉；潜入城西权贵宅邸家庙，不取物不留痕，仅布“一字止”印意牵引其自曝。
