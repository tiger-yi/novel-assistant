# 《大景镇诡使》 力量体系 (Power System)

## 第一部分：能量底层逻辑 (The Source)

### 1. 能量起源 (The Origin)
- [x] **外来论**：诡异源自于古神复苏或世界真相的渗透。
- [x] **剥削论**：人类文明的延续依赖于对诡异阴能的剥削与转化。

### 2. 能量性质 (The Nature)
- [x] **秩序 vs 混乱**：武道气血（烈阳、阳性） vs 诡异阴能（阴冷、混乱）。
- [x] **代价 (The Price)**：
    - **灵魂稳固度**：使用“真意编织”会直接磨损灵魂。
    - **记忆锚点 (Memory Anchors)**：每成功编织一个“规则碎片”，宿主的一段核心情感记忆会被强行抹去，以腾出“灵魂位”来容纳非人的规则。
    - **人性丧失**：随着编织度提高，宿主会逐渐丧失味觉、痛觉，甚至最后完全失去人类的情感逻辑，沦为披着人皮的规则集合体。
    - **生理常识剥离 (Common Sense Erosion) [NEW]**：不仅是情感，宿主会逐渐失去对人类生理常识的直觉。例如：忘记“火是烫的”、“盐是咸的”、“高处坠落会死”。这种剥离导致巡天使在非战斗状态下显得极度诡异且危险。
    - **视觉化畸变 (Visual Mutation) [NEW]**：缝合规则并非无形，而是具有不可逆的物理异化。例如，缝合空间碎片会导致躯干在光影下呈现“断层”感；缝合视觉规则会导致重瞳或眼球表面浮现规则纹路。这种畸变是巡天使被社会疏离的根本原因。

### 3. 能量形态 (The Form)
- **气态**：武道气血（外放形成气场）。
- **固态**：诡珠（击杀诡异后的掉落物，大景王朝的战略资源）。
- **规则态**：诡异规则（被剥离后可作为武学特性编织）。
- **概念态**：大景国运/民心（在特定法阵或官印中具象化）。

### 4. 吸纳与转化 (The Intake)
- **获取方式**：
    - [x] **打坐内求**：武道气血的基础修行方式。
    - [x] **杀戮掠夺**：击杀诡异获取“诡珠”或“规则碎片”。
    - [x] **契约借贷**：文官通过圣贤书或圣旨借调“国运”与“规则”。
- **转化效率**：凡人 (1%) vs 巡天使 (15%-40%) vs 天才 (60%+)。
- **能量守恒**：否。诡异阴能往往伴随着不可思议的增殖，而气血消散极快。

### 5. 环境分布 (The Distribution)
- **地域差异**：
    - **繁华城镇**：阳气汇聚，诡异蛰伏，但在阴影处仍有“阴能溢出”。
    - **禁区/荒野**：诡异横行，规则高度扭曲，普通人进入即死。
- **时间波动**：
    - **极阴之日**：月食或阴年阴月，诡异力量暴增，规则漏洞增多。
    - **末法趋势**：随着大景气运衰落，诡异出现的频率和强度正在逐年上升。

### 6. 规则兼容性与排斥反应 (Rule Compatibility & Rejection)
- **规则分类**：
    - **地缘类 (Spatial)**：涉及空间、位移、地形（如：空间错位）。
    - **因果类 (Causal)**：涉及行为触发、命运、死律（如：对视即死）。
    - **感官类 (Sensory)**：涉及五感剥夺、精神污染、幻象。
- **兼容性逻辑**：
    - 同一类别的规则碎片缝合成功率高，排斥反应轻微。
    - 跨类别缝合（如将“空间错位”与“精神污染”缝合）会产生强烈的**“规则排斥”**。
- **排斥反应表现**：
    - **肉身崩解**：缝合部位发生不可逆的畸变或坏死。
    - **精神撕裂**：规则逻辑在脑内冲突，导致认知障碍或疯狂。
    - **冷却期 (The Settle)**：每次缝合后需要大量“灵魂锚点”进行稳固，否则后续缝合极易引发连锁崩溃。

### 8. 规则位限额与融合进化 (Slot Limit & Fusion)
- **规则位 (Rule Slots)**：
    - 灵魂承载力有限，初始武者仅能承载 **3 个** 规则位。
    - 强行缝合超过限额的规则会导致灵魂瞬间崩塌。
    - 提升境界（如化生境、神游境）可缓慢增加规则位。
- **融合进化 (Rule Fusion)**：
    - 既然无法无限增加，进化的唯一路径是“融合”。
    - 将两个低阶或排斥的规则通过推演盘强行压缩、重构，升华为一个高阶规则（如：将“空间错位”+“视觉幻象”融合为“虚实之域”）。
    - 融合过程极度危险，失败则规则全失，沦为废人。

### 9. 推演噪音与逻辑毒素 (Deduction Noise & Logical Toxins) [NEW - Scenario A]
- **推演噪音 (Deduction Noise)**：
    - 规则碎片在被剥离或解析时，会释放出高频的逻辑干扰。
    - **表现**：推演盘可能出现“虚假漏洞”提示，或者在关键时刻因“算力过载”导致推演延迟 0.5-1 秒。这要求主角不能盲目依赖金手指，必须具备自身的战斗直觉。
- **逻辑毒素 (Logical Toxins)**：
    - 某些高阶或极具污染性的规则（如：因果类、疯狂类）自带“反侦察”逻辑。
    - **表现**：当推演盘强行解析此类规则时，毒素会顺着链接侵蚀宿主意识。陆斩可能会看到不存在的幻象，或者在战斗中产生错误的“预判”，将生门误认为死穴。

### 10. 体系间规则冲突 (Cross-System Friction) [Scenario A]
- **大景：阴能收割 (Shadow Harvesting)**：
    - **逻辑**：将诡异视为资源，剥离、提纯、利用。其核心是“人类对规则的强行掌控”。
    - **物理表现**：会导致区域规则“脆化”。过度收割的禁区边缘，空间如同易碎的玻璃，虽易于武者击碎（破防），但极不稳定，易引发空间坍塌。
- **南疆：生态同化 (Ecological Assimilation)**：
    - **逻辑**：不追求掌控，而是“将环境彻底非人化”。规则一旦生效，该区域的物理定律将永久改变。
    - **物理表现**：会导致区域规则“硬化”。同化区的规则场域如同实心的铁块，外来气血难以渗透，导致人类武者战力大幅缩减（如：百步穿杨的箭矢进入同化区后会因重力规则改变而瞬间落地）。
- **排斥反应 (System Friction)**：
    - 当“收割者”进入“同化区”，两者底层逻辑会发生剧烈碰撞。人类武者的气血会因为环境规则的变迁而加速流失，甚至在体内产生“规则结晶”。这也是大景边境四大藩王难以彻底平定南疆的根本逻辑原因。

### 8. 诡异经济学与阴能溢出 (Anomalous Economics & Overflow)
- **大景王朝的核心**：王朝并非纯粹的守护者，而是“诡异牧场”的管理者。封锁禁区是为了稳定收割阴能，维持大景的气运与长明灯火。
- **阴能溢出 (The Overflow)**：阴能并非完全受控。收割过程中产生的“阴能溢出”会导致环境畸变。
    - **影疾 (Shadow Malady)**：长期处于阴能溢出环境的平民，其影子会逐渐产生“重叠”或“剥离”感。重症者影子甚至会试图独立，在宿主静止时做出微弱的攻击性动作（如试图掐住宿主的喉咙）。
    - **感官致畸**：临水县的夜晚，用残片供能的“诡火灯”会散发出诱发幻听的微光。
- **阴米 (Shadow Rice)**：一种在阴能溢出的土地上生长的变异作物，是大景王朝底层的必备口粮。
    - **副作用**：虽能极快补充体力并强壮气血，但会导致“人性锚点”加速腐蚀。
    - **视觉表征**：长期食用者眼白会泛出一层极淡的灰翳，瞳孔对强光失去收缩反应。
- **职业代价**：巡天使长期处于阴能溢出环境中，会导致“职业病”——如：影子逐渐独立、味觉丧失、情感淡漠。
- **职业禁忌 (Professional Taboos)**：江湖势力规避规则的底层逻辑。
    - **漕帮禁忌**：船行雾中绝不可回头，回头即“见鬼”，河伯规则将瞬间锁死整艘船。
    - **镖局禁忌**：运输规则碎片的镖师，沿途不能说出“货”的真实名称，必须使用代号（如：将空间碎片称为“轻风”），否则会引起规则共鸣导致暴走。

### 4. 压制与越级 (The Gap)
- **位格压制**：高境界对低境界具备绝对的“灵压”与“规则优先级”。低境界规则在面对高境界时，会发生逻辑降级（如：低阶的“绝对防御”会被高阶的“普通攻击”强行贯穿）。
- **越级条件**：
    - [x] **帝兵神器**：持有推演盘或上古遗存的极品诡兵。
    - [x] **禁忌秘术**：如燃烧灵魂锚点的“自残式”爆种。
    - [x] **规则克制**：利用逻辑漏洞进行精准打击（见第四部分）。

## 第五部分：规则战斗机制 (Combat Mechanics)

### 1. 规则共振 (Rule Resonance)
- **原理**：当两种属性相似或完全相反的规则近距离接触时，会引发场域共振。
- **实战表现**：通过主动调整自身规则频率，可以强行“引爆”对方的规则。例如：利用“空间错位”去干扰对方的“隐匿规则”，使其空间坐标发生逻辑冲突从而自爆。

### 2. 逻辑漏洞 (Logical Loopholes)
- **原理**：没有任何规则是完美的，所有规则都建立在特定的逻辑闭环之上。
- **实战表现**：战斗的关键不在于力量，而在于“寻找补丁之外的漏洞”。
    - **实战案例 1（红嫁衣）**：其“空间错位”规则下，攻击无法触及其本体。但推演盘解析出，当错位空间进行“位置交换”的瞬时（0.1秒），两个空间会发生完全重合。陆斩通过抓住这0.1秒的缝隙，将攻击直接灌入其规则核心。
    - **实战案例 2（文官契约）**：文官定义的“此地不可流血”，若攻击者通过规则将对方的血液转化为“墨水”或“非血物质”，则规则失效。
- **视觉化表现**：当看破逻辑漏洞时，推演盘会映射出诡异周身的“虚线节点”或“逻辑断层”，陆斩必须在电光火石间击中这些断层。

### 3. 不同流派的规则运用 (Rule Utilization Schools)

### 1. 巡天监：掠夺与缝合 (The Inquisitors)
- **核心逻辑**：通过推演盘或暴力手段剥离规则，强行缝合进人体。
- **优缺点**：见效极快，战斗力强；但代价巨大，灵魂易崩解，伴随明显的视觉畸变。

### 2. 文官集团：群体道德契约 (The Scholars' Moral Contract)
- **核心逻辑**：通过“定义禁忌”来构建规则。非个人之力，而是依托“圣贤教化”建立的群体意识场。
- **规则表现**：**群体契约 (Collective Pact)**。例如：在一座书院辐射范围内定义“此地不可杀生”。若有人违规，则整个场域内的“浩然气”会转化为对违规者的规则束缚（如血液倒流、四肢僵死）。
- **优缺点**：副作用小，不会导致肉身畸变；但生效极其缓慢，且对施展者的道德一致性要求极高。若施展者内心产生怀疑或私欲，契约将瞬间反噬。

### 3. 民间流派：禁忌规避 (The Commoners' Taboos)
- **核心逻辑**：不掌握规则，但通过“绝对服从禁忌”来获得暂时的豁免。
- **规则表现**：如漕帮的“不回头”、镖局的“改名代号”。其本质是让自己在规则层面上“隐形”或变成“无害目标”。

### 4. 律法与文明
- **律法**：大景律例（表面）+ 规则禁忌（底层）。
- **文明演进**：[x] **技术停滞**：伟力归于规则，科技树完全歪向了“如何收割与利用诡异”。
