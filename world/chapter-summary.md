## 第 118 章：祭坛夺机
**时间/地点**：廿六夜寅时初 / 弃民坑底部石塔内部
**视角**：主角 (张启明)
**摘要正文**：
张启明进入石塔后，识破了大武帝国利用白骨祭坛抽取流民血肉提纯灵机的真相。面对祭坛顶端的纯净灵机，他险些中计，及时以“止”字悬停，发现灵机深处藏有大武律法的皇道暗记。张启明强行开启阴阳磨盘，以紫电雷骨碾碎暗记，成功吸收灵机，灵力瞬间恢复至三成，左手伤势肉眼可见愈合。恢复战力后，张启明趁势将自身雷力反向注入阵眼，试图篡夺阵法控制权，却在触及核心时惊觉底层连通着祭祀监高阶的因果监控网络，且被锁定。同时，由于阵法灵力被抽干，塔外活物失去压制，一根暗红触手砸碎石门挤入塔内。
**关键事件**：
1. 识破祭坛：揭露大武帝国用人牲血肉提纯灵机的“吃人磨盘”真相。
2. 碾碎暗记：发现并以阴阳磨盘配合雷骨强行碾碎灵机中的皇道禁制。
3. 吸收恢复：吸收灵机，灵力恢复至三成，左手伤势快速愈合。
4. 篡夺阵枢：反向注入雷力篡夺阵法，触动并被祭祀监高阶监控网络锁定。
5. 活物破门：阵法灵力被抽干导致压制失效，塔外活物砸碎石门入侵。
**人物状态更新**：
- 主角：灵力恢复至 30%，左手伤势大幅愈合，左腿仍有钝痛。状态回升。
- 老乞丐：继续惊恐躲藏。
**资源与消耗**：
- 消耗：吸收纯净灵气（已消耗）。
- 新增：获得三成灵力恢复，部分阵法控制权（被反向监控）。
**伏笔与线索**：
- [H131] 祭坛顶端的纯净灵气是否藏有陷阱？（✅ 已回收：藏有大武皇道暗记，意图将吸收者化为傀儡）
- 新埋：H132 祭坛底层连通的祭祀监高阶监控网络；H133 失去阵法压制而破门而入的活物。
**逻辑校验**：
- 战力一致性：✅ 利用功法特性强行碾碎暗记，未产生战力崩坏。
- 时间/地理一致性：✅ 承接上章入塔。
- 资源一致性：✅ 灵力从 0% 合理恢复至 30%。
**下一章承接**：
- 钩子：面对破门而入的活物和祭祀监的注视，张启明将如何应对？
- 目标：利用恢复的灵力与部分阵法控制权，解决眼前的活物危机，并切断监控网络。

## 第 119 章：雷断因果
**时间/地点**：廿六夜寅时初 / 弃民坑底部石塔内部、地脉暗道
**视角**：主角 (张启明)
**摘要正文**：
张启明面对破门而入的触手，以恢复的三成灵力催动紫电雷骨，化作青蓝雷刃将其强势斩断，逼退活物。随后，他未逃离，而是转身应对脚下祭祀监高阶监控网络的因果锁定。他以识海中的“阴阳磨盘”碾碎因果线，并反向灌入狂暴雷力，直接炸毁了数百里外祭祀监红袍祭祀的半个头颅。强行反噬导致张启明灵力再次耗尽且内腑受震。失去核心支撑的白骨祭坛坍塌，露出底部的地脉暗道。在石塔被外界活物彻底撞塌的瞬间，张启明带着老乞丐跃入暗道逃生。
**关键事件**：
1. 雷刃断触：以雷骨金纹凝聚雷刃，一击斩断二阶巅峰活物触手。
2. 绞碎锁定：以“阴阳磨盘”碾碎祭祀监高阶网络的因果锁定。
3. 反向烧毁：榨干剩余雷力反向灌入网络，重创数百里外的红袍祭祀。
4. 祭坛坍塌：失去灵力支撑的白骨祭坛及石塔在活物撞击下彻底崩塌。
5. 跃入暗道：发现并跃入祭坛底部的地脉暗道逃生。
**人物状态更新**：
- 主角：灵力再次见底，内腑受到一定震荡，左腿旧伤依然钝痛。成功解除因果锁定。
- 老乞丐：受惊吓，跟随跃入暗道。
**资源与消耗**：
- 消耗：刚恢复的三成灵力全部耗尽（用于雷法斩击和反向攻击网络）。
- 新增：摆脱祭祀监锁定；发现地脉暗道。
**伏笔与线索**：
- [H133] 失去阵法压制而破门而入的活物（✅ 已回收：被斩断触手后逼退，后撞塌石塔）。
- [H132] 祭坛底层连通的祭祀监高阶监控网络（✅ 已回收：被阴阳磨盘碾碎并反向烧毁）。
- 新埋：H134 祭坛底部的地脉暗道通向何处？；H135 被反向雷力重创的红袍祭祀身份及后续报复。
**逻辑校验**：

## 第 120 章：铜根暗河
**时间/地点**：廿六夜寅时初（承接上文） / 弃民坑底至地下暗河、青铜巨管（铜根）
**视角**：主角 (张启明)
**摘要正文**：
张启明榨干灵力斩断因果网后，带着老乞丐向暗道急速坠落，遭遇上方活物触手的追击。张启明凭借前世理气本能，识破暗道为人工开凿，遂以纯粹雷骨巨力踏碎岩层承重节点，引发大塌方将触手连同废墟彻底掩埋。两人坠入极寒的地下尸水暗河中。摆脱追击后，老乞丐点亮残破的无舌铃，照亮了暗河中的庞然大物——一截布满古老道门符文的青铜巨管。张启明剥开铜绿，发现大武帝国将远古道门梳理地脉的“铜根”剖开，灌满流民血肉残渣，改造成抽取污秽灵机的下水道。感受到铜根深处传来沉闷的搏动与微弱的道门生机，张启明将断剑绑在腕上，决定沿着铜根向深处探寻源头。
**关键事件**：
1. 踏碎岩层：坠落中以肉身巨力击碎承重节点，引发塌方掩埋追兵。
2. 坠入暗河：落入极寒尸水暗河，利用雷骨锁住体温。
3. 发现铜根：无舌铃光晕下，发现布满道门符文的青铜巨管。
4. 揭露真相：确认大武帝国污染道门铜根，将其作为输送血肉灵机的下水道。
5. 探寻源头：捕捉到铜根深处的沉闷搏动，决定沿管道深入探索。
**人物状态更新**：
- 主角：灵力彻底干涸（0%），经脉皲裂，左腿旧伤在阴寒水汽下加剧痛楚；因果网盲区形成，但半个时辰后追兵将至。
- 老乞丐：半昏迷，极度虚弱，持有残破无舌铃。
**资源与消耗**：
- 消耗：最后残存气血透支。
- 状态：玄铁桃木剑残破，仅剩剑柄绑于右手腕。
**伏笔与线索**：
