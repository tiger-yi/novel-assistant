# 力量体系

> 体系以"肉身确定性 vs 玄学天赋"为底层哲学：武夫强在可验证、可传承，吃亏在无法速成心性与对概念攻击无抗性。

## 1. 体系总览

| 字段 | 内容 |
| :--- | :--- |
| 主力量来源 | 肉身自身：气血、骨骼、经脉、寿元 |
| 能量性质 | 气血之力（肉身浓度可观测，非灵根天赋） |
| 获取方式 | 进食/苦修积累 + 战利品（妖丹、败敌之败血）炼入肉身 |
| 转化方式 | 【破限加点】以气血/寿元为"薪"兑换肉身质变；杀伐偿还：斩强敌触发参悟质变 |
| 社会成本 | 加点消耗寿元导致"老得快"；武夫被朝廷世族当作消耗品征用 |
| 核心禁忌 | 不可透支寿元过限（暴毙/衰败不可逆）；概念级/诅咒类攻击无肉身抗性 |
| 后期通胀控制 | 境界天花板（武圣之上不可言）+ 战力锚点固定"镇一县/镇一国"具象刻度；以体系之争代替纯数值比拼 |
