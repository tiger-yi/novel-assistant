# 地理与势力

## 1. 世界尺度与基础规则

| 字段 | 内容 |
| :--- | :--- |
| 世界尺度 | 单一古典大世界（大魏王朝末年至诸郡并起） |
| 核心区域层级 | 北疆流民地 → 边关武威营 → 京畿世族圈 → 山外妖域 → 诸郡割据带 |
| 交通方式 | 官道/驿道徒步、马车、漕运；山外妖域需猎队开路 |
| 通信方式 | 驿马急报、商旅传讯、斥候递信；边军烽燧 |
| 地理限制 | 饥荒导致官道盗匪横行；妖域无完整官道；驿传成本高 |
| 资源分布逻辑 | 粮=生存硬通货；妖丹=流通硬货；血/药=医疗资源；武藏典籍=战略性资源 |
