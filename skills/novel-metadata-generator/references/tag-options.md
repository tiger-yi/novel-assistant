# 标签候选项 (Tag Options)

## 1. 主分类 (Main Categories)
- **都市类**：都市高武、都市种田、都市日常、都市修真、都市脑洞、战神赘婿
- **玄幻/奇幻/仙侠类**：传统玄幻、玄幻脑洞、西方奇幻、东方仙侠
- **历史/军事类**：历史古代、历史脑洞、抗战谍战
- **悬疑类**：悬疑灵异、悬疑脑洞
- **衍生类**：男频衍生、动漫衍生
- **科幻/游戏类**：科幻末世、游戏体育

## 2. 主题标签 (Subject Tags)
- **基础大类**：玄幻、都市、历史、武侠、体育、奇幻仙侠、悬疑
- **世界背景**：古代、架空、赛博朋克、克苏鲁、高武世界、异世大陆、东方玄幻、都市异能
- **核心元素**：开局、第四天灾、规则怪谈、灵气复苏、末日求生、天灾、国运、断层、仕途、谍战、武将
- **衍生同人**：衍生、综影视、综漫
- **时代背景**：宋朝、清朝
- **叙事风格**：第一人称

## 3. 角色标签 (Character Tags)
- **情感设定**：单女主、多女主、无女主
- **职业背景**：特工、特种兵、神医、神探、游戏主播、学霸
- **地位权势**：皇帝、女帝、宫廷侯爵、大佬、大小姐、校花、赘婿
- **人格特质**：全能、天才、奶爸、反派、腹黑、扮猪吃虎

## 4. 情节标签 (Plot Tags)
- **穿越重生**：穿越、重生、魂穿、双重生、穿书、灵魂互换
- **金手指**：系统、空间、聊天群、黑科技、无敌、神豪、黑化、迪化
- **叙事流派**：升级流、无限流、诸天万界、打脸、无脑爽、1v1、无后宫、惊悚游戏
- **核心任务**：发家致富、高手下山、囤物资、捉鬼、捉妖、破案、推理、求生、争霸、科举、盗墓、鉴宝、乡村
- **职业技能**：风水秘术、剑修、剑道、美食、直播、电竞、钓鱼、外卖、宠物
