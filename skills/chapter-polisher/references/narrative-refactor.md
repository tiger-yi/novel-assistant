# 叙事重构指南 (Narrative Refactor Guide)

## ⚠️ 绝对红线 (Absolute Redlines) - 必须 100% 执行

在执行任何润色前，请深深刻入以下三条红线。违反任何一条即视为润色失败：

1.  **严禁强调标点**: 除人物对话外，严禁在任何非对话内容中使用单引号 `‘ ’` 或双引号 `“ ”` 包裹（包含术语首引、碑刻、口令等）。
2.  **严禁面板化符号**: 严禁使用 `【 】`、`[ ]`、`（ ）` 或 Markdown 列表/表格。严禁在正文中使用加粗 `** **`。
3.  **严禁解释性叙述**: 严禁通过作者视角解释设定。所有信息必须通过感官、动作、环境或角色认知流露。

## Phase 1: 任务规划 (TODO List)

在处理文本前，必须根据以下 **七大维度** 列出重构 TODO 清单：

1.  **维度一：去 AI 化与颗粒度**
    *   **指纹清理**: 严禁出现“嘴角勾起弧度”、“倒吸一口凉气”等 AI 常用词。
    *   **动词精准化**: 用具体动词（如“砸”、“拗”、“钉死”）替代“副词+通用动词”。
    *   **拒绝总结**: 执行 **Show, Don't Tell**，删除“总而言之”、“综上所述”。
    *   **替换高频词**: 将“显然”、“宛如”换成“活像”、“硬生生”。
    *   **逻辑审计**: 剔除“衔接词”（因此、所以），通过画面切换实现转折。
    *   **界面审计**: **[绝对禁止面板化]**。
        - 严禁输出 Markdown 列表、表格、Key-Value 格式（如 `属性：xxx`）。
        - 严禁使用加粗强调 `**Text**`。
        - 严禁使用面板符号 `【 】`、`[ ]`。
        - **必须转化为感官描写**（如“视网膜上投射出红光”、“指尖划过冰冷的屏幕”、“耳边响起机械的播报音”）。
    *  **标点审计**: **[去引号与括号]**。
        - 除人物对话外，严禁在任何非对话内容中使用单引号 `‘ ’` 或双引号 `“ ”` 包裹（含术语首引、碑刻、口令）。
        - 严禁使用括号 `（ ）` 进行补充说明，必须融入自然语言叙述。
        - 重写示例：碑刻→“碑面刻字：镇、禁、诫”；口令→“他在心底敕一字：止”；术语首引→直接使用无引号。

2.  **维度二：认知偏差滤镜**
    *   锁定角色偏见，屏蔽全知视角。
    *   让角色只看到他 *想* 看到的，而非事实全貌。

3.  **维度三：冰山原则与语义留白**
    *   **意象投影**: 调用 `references/physical-descriptor.md`（如有），用物件承载心理。
    *   **情感审计**: 引入非理性噪音（如不合时宜的笑、生理性的厌恶）。

4.  **维度四：节奏呼吸与陌生化**
    *   **句式波长**: 执行 **7-2-1 律动**（七分短句、二分长句、一分断裂）。
    *   **五感沉浸**: 描写身体的诚实反应（汗毛直立、胃部抽搐）。
    *   **语法审计**: 摧毁“虽然...但是...”等平衡式语法。

5.  **维度五：挖掘人性幽暗**
    *   戳破体面，描写人性中微小的自私、怯懦或贪婪。

6.  **维度六：命运的对仗与反差**
    *   在美好时刻埋下悲凉伏笔，或在绝境中透出一丝荒诞的希望。

7.  **维度七：具象的痛点锚点**
    *   聚焦微小细节（指甲缝的泥、生锈的刀柄）。

## Phase 2: ReAct 迭代循环

在重构过程中，请使用 ReAct (Thought-Action-Observation) 模式进行迭代：

### Thought (诊断与方案)
*   **人味儿诊断**: 为什么这段文字像 AI？（是词汇太通用？逻辑太顺滑？情感太直白？）
*   **平衡策略**: 如何实现 **“情绪乱”**（增加噪音）与 **“逻辑稳”**（剧情推进）的平衡？
*   **视角降落**: 方案是否真正进入了角色的主观视角？

### Action (重构行动)
*   **引入主观偏见**: 强制受限视角，删除上帝视角的解释。
*   **控制呼吸节奏**: 严格执行 **7-2-1 律动**，使用长短句交替制造节奏感。
*   **执行死律**: 多使用倒装句、倒装短语或感叹句，打破陈述句的单调。
*   **词库偏好**: 优先使用：*活像、硬生生、一动不动、刺啦* 等具体词汇。

### Observation (人性化审计)
*   **自检三问**:
    1.  **羞耻感**: 是否敢于描写角色的狼狈和不堪？
    2.  **去说教**: 是否删除了所有“作者的说教”？
    3.  **感染力**: 读者是否能通过文字感受到疼痛、寒冷或恐惧？
*   **红队扫描**: 若发现任何平稳对仗（如“既...又...”）或抽象抒情（如“悲伤逆流成河”），必须即时重写。

## Phase 3: 最终审计 (Final Audit)

1.  **去工业化**: 除人物对话外，确认 100% 删除了 Key-Value 面板、列表、`【 】`、`[ ]`、`（ ）`、单引号 `‘ ’`、双引号 `“ ”` 等系统符号。
2.  **Show, Don't Tell**: 确认没有一段是在“解释”故事，而是在“播放”画面。
