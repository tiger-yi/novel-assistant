# 长篇小说原创性审计规范 (Originality Audit)

本规范识别长篇小说中的同质化、长线疲劳与逻辑硬伤，通过世界观增色和剧情降噪维持作品的长期生命力。它是完整原创性审计 pipeline 的唯一流程与维度来源；`trope-blacklist.md` 作为可独立加载的桥段参考库保留。

涉及 `world/outline.md` 的章节或世界更新，必须通过 `periodic-trigger-classification` 语义门禁，判断是否产生 `arc_completed` 或 `premise_changed`；无触发时使用附原因的 `NOT_APPLICABLE`。`初始化世界` 的 `outline_initialized` 由事务执行器自动记录。

## 输入与边界

- **核心输入**: `world/outline.md`、`world/characters.md`、`world/power.md`、`world/geography.md`、章节摘要及必要正文证据。
- **输出**: 结构化审计结论、风险证据与两档优化方案。
- **默认副作用**: 只读。建议不得自动同步到 World Bible；需要写入时必须另行取得写命令授权并创建事务。
- **证据要求**: 每项结论引用实际文件，并按场景提供章节 ID 或实体 ID；不得用完整内部推理链替代证据。

## 核心流程

1. **数据对齐**: 检查 World Bible 完整性、初期设定与长线主线的耦合度及设定废弃风险。
2. **维度审计**: 逐项执行 A-K 审计，并对照 `trope-blacklist.md`。
3. **长篇展开性审计**: 第一章发布前必须执行 L 维审计，判断 World Bible 是否具备长期展开、分支回流和势力渗透能力。
4. **故事力基线审计**: 第一章发布前必须执行 M 维审计，判断 World Bible 是否已经把人物、主题、冲突、反转和角色功能转化为可写作的章节牵引。
5. **交叉验证**: 将力量、人物、势力、资源、时间、信息流、故事力基线和剧情循环风险相互校验，避免单维优化制造新冲突。
6. **方案生成**: 输出“稳健微调”与“底层革新”两套差异化方案，说明收益、代价和影响文件，并形成可验收的返工条件。
7. **门禁判定**: 使用 `PASS`、`WARN`、`FAIL` 或附原因的 `NOT_APPLICABLE`；周期审计存在 `FAIL` 时阻断下一创作周期。

## A-K 审计维度

### A. 世界观与底层逻辑

- **问题**: 是否只是替换名词的常见玄幻模板；势力冲突是否有经济、政治与生存逻辑。
- **动作**: 检查 `power.md` 是否只有等级堆叠，检查 `geography.md` 的领地、资源和冲突动机。
- **结论**: 标记换皮倾向、设定废弃点及可形成独特因果链的世界规则。

### B. 战力平衡与成长

- **问题**: 金手指是否消除挑战；中后期数值膨胀是否使前期规则失效。
- **动作**: 模拟后期对战，核对人物能力、力量阶梯、底牌来源和代价。
- **结论**: 标记战力失衡点，并评估相性克制、环境限制或规则对抗方案。

### C. 人设长线生命力

- **问题**: 主角与反派的行为是否具有必然性，人物是否只重复固定功能。
- **动作**: 追踪不同阶段的动机、执念、关系与道德困境，核实反派手段与目标的因果关系。
- **结论**: 识别降智反派、工具人和缺乏变化的主角弧线。

### D. 剧情节奏与创新

- **问题**: 是否形成换地图重开、拍卖会冲突、比武升级等机械循环。
- **动作**: 对比 `trope-blacklist.md`，检查前三章钩子、卷级转折、重复解决模式和高预测开局桥段。
- **结论**: 标记读者疲劳区间，并提出改变进入方式、目标或代价结构的方案。

### E. 视觉与命名

- **问题**: 人名、术语、职业与人物外显特征是否带有流水线感。
- **动作**: 检查重名风险、撞库风险、空洞标签和缺乏职业细节或性格缺陷的角色。
- **结论**: 输出需要重命名、增加识别锚点或补充生活细节的对象。

### F. 桥段降噪

- **问题**: 开局与关键冲突是否依赖读者已熟悉的固定误会和打脸模板。
- **动作**: 找出桥段实际承担的剧情功能，再改变身份、因果、地点或结果，而不是只替换表面元素。
- **结论**: 提供保留功能但降低既视感的重构方案。

### G. 代价与人性锚点

- **问题**: 力量获取是否过于廉价，人物是否在成长中失去可感知的人性风险。
- **动作**: 核对人物锚点、能力代价与大纲中的实际支付证据。
- **结论**: 标记无代价升级，并提出与主题相符且可持续兑现的代价机制。

### H. 规则兼容性与逻辑

- **问题**: 不同力量规则结合时是否出现万能钥匙或缺乏排斥成本。
- **动作**: 对比力量体系的兼容关系，模拟融合、克制和失败场景。
- **结论**: 明确规则边界、漏洞条件与不可绕过的失败代价。

### I. 社会运行与沉浸感

- **问题**: 世界规则是否只在战斗时出现，未进入衣食住行、交易和公共秩序。
- **动作**: 检查地理、经济、照明、饮食、货币、交通和职业是否受核心规则影响。
- **结论**: 识别悬浮设定，并提出能在日常场景持续出现的世界反馈。

### J. 组织势力与资源逻辑

- **问题**: 势力结构是否与修炼体系、领地和资源闭环；非人势力是否只有零散个体。
- **动作**: 对比势力等级、资源来源、领地划分、组织目标与冲突成本。
- **结论**: 标记缺乏组织逻辑的势力，并提出与力量体系匹配的组织形态。

### K. AI 结构风险

- **问题**: 章节或大纲是否存在 L3 结构层 AI 痕迹，包括人名撞库、高预测桥段、核心设定同质化、系统或金手指表达过熟。
- **动作**: 承接 `chapter-polish.md` 记录的 L3 风险，结合正文证据、World Bible 和 `trope-blacklist.md` 判断风险是否属于局部表达、桥段功能或底层设定。
- **结论**: 对局部表达风险退回润色处理；对桥段和设定风险输出稳健微调与底层革新两档方案。不得只为降低检测分数而改动核心设定。

### L. 长篇展开性审计

第一章发布前, 本维度为必审模块。其目标不是寻找更多桥段, 而是确认八类 World Bible 能支撑长篇连续展开。

- **主线-支线回流**: `outline.md` 不得只有 `A -> B -> C -> D -> 大结局` 的单线串联。主线应像鱼骨图: 主骨清楚, 支线通过人物、势力、资源、情报、伏笔或时间压力回流主线。每条重要支线必须改变至少一项信息、资源、关系、势力格局、时间压力或线索状态。
- **金手指生态位**: 金手指必须绑定世界核心矛盾, 并在 `power.md` 中体现社会成本、核心禁忌、反制方式、失败代价和后期通胀控制。不得只是主角收益按钮。
- **分卷承压**: 每卷必须有独立目标、代价、状态变化和卷间因果。不得只形成升级、换地图、再升级的机械循环。
- **反派与势力路线图**: `geography.md` 与 `characters.md` 必须证明主要势力和关键对手有自身目标、资源、控制区域、敌友关系和阶段行动, 不得只在主角到达时临时刷新。
- **势力渗透引入**: 后期势力应先通过税、法、货币、交通、传闻、禁令、商品、宗教、职业、通缉或通信条件进入读者视野, 再正式登场。
- **资源经济**: `inventory.md` 与 `geography.md` 必须说明关键资源从哪里来、谁控制、如何流通、为何稀缺、如何消耗。不得需要什么就临时获得什么。
- **时间压力**: `timeline.md` 必须能承载倒计时、多线行动、敌方推进、赶路成本和闭关成本。不得让主角行动不受时间代价约束。
- **信息流**: 审计谁知道什么、何时知道、通过什么渠道知道、可信度如何。情报与通信条件必须能支撑冲突, 不能制造便利的全知或失明。
- **人物驱动**: `characters.md` 必须区分核心欲望、性格边界、人性锚点、禁忌代价、重要人物资源与弱点。人物不得只服务剧情节点。
- **伏笔承诺密度**: `hooks.md` 中主线、卷级、局部线索应有叙事层级和预计解决/回收范围。不得堆积悬念而没有兑现计划。

第一章前的 L 维审计 `FAIL` 必须阻断 `创作第 1 章`。`WARN` 可由用户接受后放行, 但只保留到 `CH-0010` 或 `ARC-001` 卷终二者较早处复查一次；已缓解或未恶化即关闭, 已恶化则升级为新一轮 `WARN` 或 `FAIL`。

### M. 故事力基线审计

第一章发布前, 本维度为必审模块。其目标不是评价文笔, 而是确认 World Bible 已经具备可连续创作的故事动力。

- **人物驱动**: `characters.md` 必须证明核心视角人物有主动目标、底层动机、性格边界、缺陷或误判、禁忌代价和弧光方向。主角不得只是事件承受者或收益领取者。
- **主题透镜**: `outline.md` 必须用一句话记录故事反复验证的问题或价值冲突, 并让卷目标、主要对手和关键选择共同服务该主题。不得把题材、爽点或世界设定当主题。
- **有效冲突**: ARC-001 至少包含内心冲突、人物冲突、外部冲突中的两类, 且冲突必须改变资源、关系、信息、时间压力或势力格局。单纯打脸、误会或升级不能独立构成有效冲突。
- **情理内反转**: `outline.md` 或 `hooks.md` 必须登记至少一个主线或卷级反转种子, 包含铺垫位置、表面误导、真实指向、触发条件和预计回收范围。无铺垫的临时揭示按高风险处理。
- **角色功能收束**: `characters.md` 与 `geography.md` 中的重要人物、反派和势力必须有目标、资源、弱点、行动路线和叙事功能。只承担标签、氛围或一次性介绍的人物不得进入核心表。
- **开篇牵引**: 黄金三章必须完成“切入事件 -> 反馈代价 -> 目标锁死”的连续牵引, 每章章末牵引要服务主线而不是新增无关悬念。
- **展示优先**: World Bible 只能记录可被章节行动、选择、对话、资源消耗或线索变化展示的主题和人物特质；空洞形容词和旁白式说明不能作为通过证据。

第一章前的 M 维审计 `FAIL` 必须阻断 `创作第 1 章`。`WARN` 可由用户接受后放行, 但必须在 `CH-0010` 或 `ARC-001` 卷终二者较早处复查一次。

## 差异化修正策略

- **力量体系**: 常见境界名称只有在机制、职能或代价形成独特因果时才成立；金手指必须与世界核心矛盾绑定。
- **势力架构**: 宗门、家族和组织的护短、扩张或敌对行为必须服务于可追踪的生存动机。
- **地图切换**: 主角应携带既有身份、资源和后果进入新地图，避免每次重新成为被羞辱的底层角色。
- **拍卖与交易**: 可改造成情报交换、诱饵布局或利益联盟，不默认使用捡漏加二世祖竞价。
- **人物对立**: 反派优先成为主角理念或选择的镜像，而不是只承担送资源和制造打脸的功能。
- **胜利来源**: 将金手指临时升级或对手降智造成的偶然胜利，重构为已有信息、代价和决策共同导出的必然结果。
- **故事力补强**: 若 World Bible 设定丰富但故事不动，优先补主角主动目标、主题透镜、有效冲突、反转铺垫和配角功能；不得只增加新势力、新术语或新地图。
- **检测降噪**: AIGC 检测器结果只作为风险信号。优先修复高预测结构、人名和桥段功能，不得以固定噪音、粗口、强制反转或破坏长篇连续性作为方案。

## 输出格式

### 审计结论

- **总体状态**: `PASS` / `WARN` / `FAIL`
- **风险项**: 维度、结论、证据、影响范围和修复优先级。
- **长线诊断**: 预计出现疲劳、战力失控或人物失真的阶段。
- **故事力诊断**: 人物驱动、主题透镜、有效冲突、情理内反转、角色功能和黄金三章牵引的通过/风险证据。

### 差异化方案

- **方案 A：稳健微调**: 不改变核心体系，只调整局部因果、代价和表达。
- **方案 B：底层革新**: 重构世界规则、金手指或长期冲突，并列出迁移成本。

### 后续授权

审计输出只提出候选方案。用户选择方案后，仍需通过相应写命令与事务执行器更新 World Bible。

第一章发布前需要全量重写八类 World Bible 时, 使用 `返工初始化世界`。该命令必须消费本审计记录、返工验收条件和用户补充要求, 先生成候选预览与差异摘要, 用户确认后再由事务执行器替换正式目标。第一章发布后不得使用初始化返工模式。
