# 命令协议: 归档世界 (archive-world)

> **人工触发词**: `归档世界`

## 功能

将到期的 World Bible 历史迁移至 `world/archive/`，并在活跃文件保留稳定索引。归档可由人工指令单独触发，也可作为 `创作第 N 章` 的条件归档子步骤自动触发。

## 授权语义

所有归档入口必须满足 `INV-ARCHIVE-001`。

- 用户输入 `归档世界`，授权执行本次无歧义的归档预览。
- 用户输入 `创作第 N 章`，同时授予该章节事务一次条件归档授权；只有达到触发条件且预览无歧义时自动执行。
- 预览出现事实冲突、重复但无法判重、范围扩大或目标不明确时停止归档并标记 `ARCHIVE_PENDING`。

## 前置条件

- 章节主体事务的发布、World Bible 回写和 Postflight 已通过。
- 归档来源、目标、章节区间或实体 ID 已列明。
- 目标归档不存在无法解释的重复记录。

## 执行流程

1. 按 `archiving-spec.md` 判断卷终、每 10 章周期或实体离场条件。
2. 未到期时记录 `NOT_DUE`，不迁移文件。
3. 到期时生成来源、目标、ID/章节区间和保留索引预览。
4. 无歧义时在事务 staging 准备归档目标与活跃索引候选，由事务执行器校验基线后执行迁移并校验链接锚点；有歧义时保持正式文件不变并记录待处理原因。
5. 重复执行时按实体 ID 或章节区间判重，不得重复追加。

条件归档的歧义不会否定已通过 Postflight 的章节主体事务，但不能将归档子状态报告为成功。
