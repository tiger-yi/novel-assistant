# 命令协议: 创建写作风格 (create-style)

> **触发词**: "创建写作风格"

## 功能
深度定制写作风格指南, 确保全书文风统一、可支撑长篇连载续航，并降低 AI 工业感。候选写入事务 staging，正式输出由事务执行器发布至 `writespec/style-guide.md`。

## 命令契约

- **输入**: 已初始化的 World Bible 和用户明确的文风偏好。
- **前置条件**: 若 `writespec/style-guide.md` 已存在，先展示变更范围并取得覆盖确认。
- **准备写入**: Agent 只写事务 staging 中的 `writespec/style-guide.md` 候选版本。
- **正式写入范围**: 仅由事务执行器发布 `writespec/style-guide.md`。
- **成功标准**: 文档 frontmatter 包含 `schema: novel-harness/style/v1`、`status: ready` 与 `style_basis`，保留项目专属设定，包含机器可提取的必需章节与 `### 黑名单词` 小节，并通过 Harness 校验。

若用户未给出明确文风偏好，Agent 必须先基于 World Bible 提出 2-3 个风格候选并等待用户选择；未经用户确认的候选只能保持 `status: draft`，不得直接发布为 `ready`。

### INV-STYLE-001 风格就绪结果

首次创作章节前，`writespec/style-guide.md` 必须满足本命令的成功标准并通过 Harness 校验。门禁只验证当前文件结果，不追踪该文件是否由本命令、人工编辑或迁移生成。

完整章节创作还必须校验风格身份锚点：`style_basis.title` 与 `world/outline.md` 书名一致，且 `genre`、`tone`、`protagonist_identity`、`cheat`、`core_taboo` 字段存在且非空。该锚点不使用 World Bible 文件指纹；流派、主调、金手指和核心禁忌是否仍适用，由 Agent 在初始化世界、修订卷规划或重大设定变更时提交语义判断。

## 执行流程 (Protocol)

### 1. 分析基本面
深度读取 `world/` 目录, 提取大纲、核心梗、金手指机制、角色信息及力量体系代价, 分析作品的"底层色调" (极致压抑、黑色幽默、热血横推等)。

### 2. 身份设定
基于基本面, 化身特定流派的白金作家 (诡异流大神、无敌流鼻祖等), 确立独特叙事特长 (宏大叙事/杀伐果断/升级体系/草蛇灰线) 与语言节奏。

### 3. 多维规范生成
生成全方位的写作指南写入事务 staging。完成内容审阅后才可将候选版本的 `status` 设为 `ready`; 草稿阶段使用 `status: draft`。必须包含:
- **风格来源依据**: 记录用户文风偏好、World Bible 引用和取舍理由；偏好缺失时只能保留候选方案，不得设为 `ready`。
- **核心调性**: 作品整体氛围感与情绪基调。
- **语言风格**: 中式民俗意象 (纸扎、丧葬、香火、古井、槐树), 拒绝西方奇幻比喻; 关键段优先选择 1-2 个最有区分度的感官、身体或物件细节，避免机械堆叠感官通道。
- **排版规范**: 段落 3-5 行为主; 场景切换/角色出场/情绪峰值/时间跳转处空行; 动作引导+冒号+引号对话; 非对话引号、引述他人曾说过的话、术语和心声包装必须遵循 `INV-CHAPTER-001`; 破折号和省略号必须符合 `INV-CHAPTER-001` 的语义边界; 省略号统一"……"; 每章感叹号 ≤3。
- **叙事策略**: 强制锁定受限视角, 执行认知偏差滤镜; 用具体物件承载心理而非抽象抒情 (参照 `chapter-polish.md` 的“物理化重组”)。
- **长篇续航结构**: 说明卷节奏、兑现密度、低冲突章节写法和疲劳控制，避免全书只复用同一种爽点循环。
- **可变项与不可变项**: 区分可随卷、场景和角色阶段变化的语速、密度、氛围，与必须全书稳定的核心禁忌、受限视角、力量代价和正文边界。
- **爽点结构**: 欲扬先抑 / 阶梯式震惊侧写 / 节奏呼吸，并说明不同阶段的兑现方式如何变化。
- **角色刻画**: 主角/配角/反派差异化, 人性幽暗审计, 配角独立动机。
- **主角成长声线**: 说明压抑期、破局期、扩张期和高位期的叙述重心、判断语气和行动表达差异。
- **角色语音表**: 为核心角色、重要阵营和反派列出说话重心、禁用口癖、冲突表达方式和可复用语气边界。
- **描写质感**: 动词精准化, 聚焦"具象痛点锚点"与"非理性噪音"。
- **语言对话**: 对话格式铁律 + 潜台词设计。
- **战斗与博弈**: 试探/布局 -> 底牌博弈 -> 终结/变数 三段式。
- **力量代价表达**: 将 `world/power.md` 的代价落成身体、环境、资源、关系或后续行动限制，不得把风格表达写成新能力或新设定。
- **低冲突场景质感**: 规定过渡、赶路、休整、信息交换和关系推进场景如何保留事件压力、人味和章末牵引，禁止注水式闲聊。
- **去 AI 化与颗粒度**: 指纹清理黑名单词, Show-Don't-Tell, 替换高频词, 逻辑审计剔除衔接词。
- **禁忌与避坑**: 列出题材易犯的降智套路与陈腐词汇，并引用 `INV-CHAPTER-001` 作为正文呈现边界的唯一权威。
- **风格应用证据格式**: 为后续章节的 `style-application-evidence` 提供引用方式，至少覆盖核心调性、受限视角/认知偏差、人物声线、节奏或爽点结构、题材质感/黑名单规避。

高风险维度必须使用结构化矩阵呈现。每个维度必须包含:

- **维度 ID**: 使用 `STYLE-<DOMAIN>-NNN` 格式，候选文件内唯一；协议不固定具体编号全集，但必须覆盖高风险维度。
- **写法规则**: 描述可执行的正文写法、禁用写法和优先级。
- **World Bible 依据**: 引用具体 `world/` 文件、章节或实体；无法引用时不得用推断补齐。
- **可变边界**: 说明该维度可随卷、场景、角色阶段变化的部分，以及必须保持稳定的部分。
- **后续应用证据点**: 规定 `style-application-evidence` 如何引用该维度 ID 和正文位置。

必须纳入结构化矩阵的高风险维度包括: 核心调性、受限视角/认知偏差、人物声线、主角成长声线、力量代价表达、爽点/节奏结构、低冲突场景质感、伏笔与章末牵引、黑名单/反模板约束。其他维度可保留普通说明，但不得与矩阵维度冲突。

用户文风偏好必须结构化记录:

- **原始偏好**: 保留用户原话或明确说明用户未提供。
- **解释后的写作取向**: 说明偏好如何转化为核心调性、语言密度、节奏和人物声线。
- **拒绝采用的取向**: 列出与当前 World Bible、正文边界或用户偏好冲突的文风方向。
- **取舍理由**: 逐项引用用户偏好或 World Bible 依据；偏好缺失时只能输出 2-3 个 `draft` 候选并等待选择。

本命令只能引用和解释既有 World Bible 事实。若发现大纲、角色、力量、伏笔或其他世界事实不足以支撑风格规范，必须报告缺口并保持 `status: draft`，不得在风格命令中新增或改写 World Bible。

frontmatter 必须包含以下风格身份锚点:

```yaml
style_basis:
  title: 书名
  genre: 流派
  tone: 主调
  protagonist_identity: 主角/叙事身份设定
  cheat: 金手指
  core_taboo:
    - 核心禁忌
```

Harness 至少校验以下标题存在：`## 2. 核心调性`、`## 4. 排版规范`、`### 受限视角`、`## 7. 角色刻画重点`、`## 11. 禁忌与避坑`、`### 黑名单词`。`创作第 N 章` 不满足 `INV-STYLE-001` 时必须熔断，可提示执行本命令或修复现有文件，但不得在章节事务中自动生成或猜测全书文风。

候选版本通过风格门禁并获得必要覆盖确认后，事务执行器校验正式目标基线并发布；覆盖确认必须在 YAML 事务中精确绑定 `writespec/style-guide.md`，Agent 不得直接覆盖正式风格文件。

### 4. 补充题材特有写法
基于基本面与多维规范, 补充该题材的独有写作规范。

### 5. 长篇适配验收
候选版本在设为 `ready` 前，必须给出可审阅的长篇适配验收清单，并逐项引用 `world/` 证据或说明适用边界:

- **最低依据**: 必须引用 `world/outline.md`、`world/characters.md`、`world/power.md`、`world/hooks.md`；按需引用 `world/chapter-summary.md`、`world/timeline.md`、`world/inventory.md`、`world/geography.md`。
- **卷节奏**: 说明不同卷或阶段的情绪递进、兑现密度和疲劳控制，避免全书只靠同一种爽点循环。
- **主角成长声线**: 说明主角在压抑期、破局期、扩张期和高位期的叙述差异，禁止后期仍沿用开局弱势语气。
- **角色语音稳定**: 为核心配角、反派和重要阵营给出可复用的说话重心、避用句式和冲突表达方式。
- **力量代价叙述**: 绑定 `world/power.md` 的代价逻辑，说明越级、连战、重伤和资源消耗在语言上如何呈现。
- **伏笔与章末牵引**: 说明悬念钩子、伏笔证据和章末牵引如何融入自然正文，不得暴露 Harness ID 或作者调度话语。
- **卷内变化边界**: 允许局部场景改变语速、密度和氛围，但不得改变 `style_basis` 的流派、主调、金手指和核心禁忌。
- **反模板约束**: 针对本题材列出高风险套路、廉价反应和同质化桥段，并给出替代写法原则。

`longform-style-readiness` 语义门禁只接受 `PASS`，必须产出事务 artifact/YAML 证据。任一验收项缺少 World Bible 依据或只给通用口号时，候选保持 `status: draft`，补齐后才可进入风格门禁。

`longform-style-readiness` 证据必须至少包含以下 YAML 字段:

```yaml
longform_style_readiness:
  basis_refs:
    - source: world/outline.md
      used_for: 卷节奏/核心冲突/主角阶段
  dimension_matrix:
    - id: STYLE-TONE-001
      rule_summary: 核心写法摘要
      world_basis:
        - world/outline.md
      variable_boundary: 可变与不可变边界
      evidence_usage: 后续章节证据引用方式
  risk_controls:
    - risk: 高风险套路或风格跑偏点
      control: 替代写法或限制规则
  draft_blockers:
    - blocker: 缺失的 World Bible 依据或用户决策
      required_resolution: 补齐方式
  ready_decision:
    status: PASS | BLOCKED_DRAFT
    rationale: 放行或保持草稿的证据摘要
```

`ready_decision.status` 只有在所有高风险维度具备 World Bible 依据、用户偏好已确认或候选已被选定、且无 `draft_blockers` 时才可为 `PASS`。存在阻断缺口时，候选 frontmatter 必须保持 `status: draft`，不得用风格文件反向定义设定，也不得把合理推断写成 World Bible 事实。

### 6. 示例演练
针对当前作品实际存在的高频长篇场景, 提供至少三组不同维度的"范文片段"；其中至少一组必须覆盖低冲突或过渡场景，如赶路、休整、信息交换、关系推进或战后整理。示例必须引用当前 World Bible 的具体人物、场景、力量、伏笔或冲突事实，禁止使用泛化玄幻样例，禁止在示例中新增设定。

每组示例必须同时包含:

- **事实依据**: 标明引用的 World Bible 文件和实体；依据不足时该组只能作为待补草稿。
- **错误写法**: 展示该题材最容易出现的 AI 味、套路化或违背长篇续航的问题。
- **修正写法**: 以当前 World Bible 的人物、力量、场景或冲突为依据改写。
- **修正理由**: 简述它如何符合受限视角、人物声线、力量代价、章末牵引或 `INV-CHAPTER-001`，并引用相关风格维度 ID。
