# 命令协议: 创建写作风格 (create-style)

> **触发词**: "创建写作风格"

## 功能
深度定制写作风格指南, 确保全书文风统一, 彻底去除 AI 味。候选写入事务 staging，正式输出由事务执行器发布至 `writespec/style-guide.md`。

## 命令契约

- **输入**: 已初始化的 World Bible 和用户明确的文风偏好。
- **前置条件**: 若 `writespec/style-guide.md` 已存在，先展示变更范围并取得覆盖确认。
- **准备写入**: Agent 只写事务 staging 中的 `writespec/style-guide.md` 候选版本。
- **正式写入范围**: 仅由事务执行器发布 `writespec/style-guide.md`。
- **成功标准**: 文档 frontmatter 包含 `schema: novel-harness/style/v1`、`status: ready` 与 `style_basis`，保留项目专属设定，包含机器可提取的必需章节与 `### 黑名单词` 小节，并通过 Harness 校验。

### INV-STYLE-001 风格就绪结果

首次创作章节前，`writespec/style-guide.md` 必须满足本命令的成功标准并通过 Harness 校验。门禁只验证当前文件结果，不追踪该文件是否由本命令、人工编辑或迁移生成。

完整章节创作还必须校验风格身份锚点：`style_basis.title` 与 `world/outline.md` 书名一致，且 `genre`、`tone`、`protagonist_identity`、`cheat`、`core_taboo` 字段存在且非空。该锚点不使用 World Bible 文件指纹；流派、主调、金手指和核心禁忌是否仍适用，由 Agent 在初始化世界、修订卷规划或重大设定变更时提交语义判断。

## 执行流程 (Protocol)

### 1. 分析基本面
深度读取 `world/` 目录, 提取大纲、核心梗、金手指机制、角色信息及力量体系代价, 分析作品的"底层色调" (极致压抑、黑色幽默、热血横推等)。

### 2. 身份设定
基于基本面, 化身特定流派的白金作家 (诡异流大神、无敌流鼻祖等), 确立独特叙事特长 (宏大叙事/杀伐果断/升级体系/草蛇灰线) 与语言节奏。

### 3. 多维规范生成
生成全方位的写作指南写入事务 staging。完成内容审阅后才可将候选版本的 `status` 设为 `ready`; 草稿阶段使用 `status: draft`。必须包含:
- **核心调性**: 作品整体氛围感与情绪基调。
- **语言风格**: 中式民俗意象 (纸扎、丧葬、香火、古井、槐树), 拒绝西方奇幻比喻; 每段至少 2 个不同感官通道, 描写身体诚实反应。
- **排版规范**: 段落 3-5 行为主; 场景切换/角色出场/情绪峰值/时间跳转处空行; 动作引导+冒号+引号对话; 非对话引号、引述他人曾说过的话、术语和心声包装必须遵循 `INV-CHAPTER-001`; 省略号统一"……"; 每章感叹号 ≤3。
- **叙事策略**: 强制锁定受限视角, 执行认知偏差滤镜; 用具体物件承载心理而非抽象抒情 (参照 `chapter-polish.md` 的“物理化重组”)。
- **爽点结构**: 欲扬先抑 / 阶梯式震惊侧写 / 节奏呼吸。
- **角色刻画**: 主角/配角/反派差异化, 人性幽暗审计, 配角独立动机。
- **描写质感**: 动词精准化, 聚焦"具象痛点锚点"与"非理性噪音"。
- **语言对话**: 对话格式铁律 + 潜台词设计。
- **战斗与博弈**: 试探/布局 -> 底牌博弈 -> 终结/变数 三段式。
- **去 AI 化与颗粒度**: 指纹清理黑名单词, Show-Don't-Tell, 替换高频词, 逻辑审计剔除衔接词。
- **禁忌与避坑**: 列出题材易犯的降智套路与陈腐词汇，并引用 `INV-CHAPTER-001` 作为正文呈现边界的唯一权威。

frontmatter 必须包含以下风格身份锚点:

```yaml
style_basis:
  title: 书名
  genre: 流派
  tone: 主调
  protagonist_identity: 主角/叙事身份设定
  cheat: 金手指
  core_taboo:
    - 核心禁忌
```

Harness 至少校验以下标题存在：`## 2. 核心调性`、`## 4. 排版规范`、`### 受限视角`、`## 7. 角色刻画重点`、`## 11. 禁忌与避坑`、`### 黑名单词`。`创作第 N 章` 不满足 `INV-STYLE-001` 时必须熔断，可提示执行本命令或修复现有文件，但不得在章节事务中自动生成或猜测全书文风。

候选版本通过风格门禁并获得必要覆盖确认后，事务执行器校验正式目标基线并发布；覆盖确认必须在 YAML 事务中精确绑定 `writespec/style-guide.md`，Agent 不得直接覆盖正式风格文件。

### 4. 补充题材特有写法
基于基本面与多维规范, 补充该题材的独有写作规范。

### 5. 示例演练
针对当前大纲核心场景, 提供至少三组不同维度的"范文片段" (战斗描写、日常对话、系统结算等)。
