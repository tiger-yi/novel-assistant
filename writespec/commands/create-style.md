# 命令协议: 创建写作风格 (create-style)

> **触发词**: "创建写作风格"

## 功能
深度定制写作风格指南, 确保全书文风统一, 彻底去除 AI 味。输出保存至 `writespec/style-guide.md`。

## 命令契约

- **输入**: 已初始化的 World Bible 和用户明确的文风偏好。
- **前置条件**: 若 `writespec/style-guide.md` 已存在，先展示变更范围并取得覆盖确认。
- **写入范围**: 仅 `writespec/style-guide.md`。
- **成功标准**: 文档 frontmatter 包含 `schema: novel-harness/style/v1` 与 `status: ready`，保留项目专属设定，包含机器可提取的必需章节与 `### 黑名单词` 小节，并通过 Harness 校验。

## 执行流程 (Protocol)

### 1. 分析基本面
深度读取 `world/` 目录, 提取大纲、核心梗、金手指机制、角色信息及力量体系代价, 分析作品的"底层色调" (极致压抑、黑色幽默、热血横推等)。

### 2. 身份设定
基于基本面, 化身特定流派的白金作家 (诡异流大神、无敌流鼻祖等), 确立独特叙事特长 (宏大叙事/杀伐果断/升级体系/草蛇灰线) 与语言节奏。

### 3. 多维规范生成
生成全方位的写作指南写入 `writespec/style-guide.md`。完成内容审阅后才可将 `status` 设为 `ready`; 草稿阶段使用 `status: draft`。必须包含:
- **核心调性**: 作品整体氛围感与情绪基调。
- **语言风格**: 中式民俗意象 (纸扎、丧葬、香火、古井、槐树), 拒绝西方奇幻比喻; 每段至少 2 个不同感官通道, 描写身体诚实反应。
- **排版规范**: 段落 3-5 行为主; 场景切换/角色出场/情绪峰值/时间跳转处空行; 动作引导+冒号+引号对话; 省略号统一"……"; 每章感叹号 ≤3。
- **叙事策略**: 强制锁定受限视角, 执行认知偏差滤镜; 用具体物件承载心理而非抽象抒情 (参照 physical-descriptor.md)。
- **爽点结构**: 欲扬先抑 / 阶梯式震惊侧写 / 节奏呼吸。
- **角色刻画**: 主角/配角/反派差异化, 人性幽暗审计, 配角独立动机。
- **描写质感**: 动词精准化, 聚焦"具象痛点锚点"与"非理性噪音"。
- **语言对话**: 对话格式铁律 + 潜台词设计。
- **战斗与博弈**: 试探/布局 -> 底牌博弈 -> 终结/变数 三段式。
- **去 AI 化与颗粒度**: 指纹清理黑名单词, Show-Don't-Tell, 替换高频词, 逻辑审计剔除衔接词。
- **禁忌与避坑**: 列出题材易犯的降智套路与陈腐词汇; 正文严禁 `【 】`、`[ ]`、`（ ）`、列表/表格、加粗; 非对话严禁引号。

Harness 至少校验以下标题存在：`## 2. 核心调性`、`## 4. 排版规范`、`### 受限视角`、`## 7. 角色刻画重点`、`## 11. 禁忌与避坑`、`### 黑名单词`。`创作第 N 章` 在状态不是 `ready` 时必须熔断，不得自动生成或猜测全书文风。

### 4. 补充题材特有写法
基于基本面与多维规范, 补充该题材的独有写作规范。

### 5. 示例演练
针对当前大纲核心场景, 提供至少三组不同维度的"范文片段" (战斗描写、日常对话、系统结算等)。
