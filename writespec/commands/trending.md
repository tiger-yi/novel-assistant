# 命令协议: 热门话题 (trending)

> **触发词**: "热门话题"

## 指令说明
基于执行当日可核验的公开信息，分析番茄、七猫、起点等目标平台的近期风向，为百万字长篇提供选题参考。不得把固定年份、既有题材偏好或模型记忆表述为“最新趋势”。

## 命令契约

- **输入**: 目标平台、受众、题材边界和观察时间窗；缺失时明确采用的默认值。
- **时效性**: 报告必须记录检索日期、来源链接和信息发布日期。
- **失败处理**: 无法联网或缺少近期来源时，标记“无法验证最新趋势”，不得伪造结论。
- **写入范围**: 仅写入 `analysis/trending-analysis.md`，不得修改 World Bible。

## 执行流程 (Protocol)

### 1. 核心赛道检索与分析
使用可用的网络检索工具校准目标平台；至少引用两个相互独立且在时间窗内的来源。以下赛道仅作为候选，不是固定答案:
- **新派历史**: 检索"工业大摸底"、"国运流小说 风向"。关注"降维打击"与"民族情绪"结合点 (手搓光刻机、国运绑定)。
- **都市脑洞**: 检索"规则怪谈 职业流"、"直播 诡异 复苏"。关注"冷门职业成神"与"规则/克系"融合。
- **极道横推**: 检索"肉身成圣 小说"、"消耗寿元 加点流"。关注极致暴力美学与快节奏爽点。

### 2. 潜力黑马与短剧适配性扫描
- 检索"短剧改编风口"、"反套路 战神/神医"。
- 挖掘适合视觉化呈现的题材: 现代神医/战神微创新 (下山高手+豪门、奶爸/宠妹)、脑洞鉴宝/捡漏。

### 3. 创作风向标校准 (避坑指南)
- **节奏检查**: 验证"黄金前 500 字"原则 (开篇即高潮)。
- **人设去味**: 主角"去爹味", 打造"精致利己主义"或"唯我独法"人设。
- **系统优化**: 金手指单一且强大 (如仅"加点"或"签到"), 避免复杂数据计算。
- **情绪审计**: 所有剧情服务于"爽、怒、燃、泪"四大情绪价值。

### 4. 输出推荐方案
提供 3 组符合当前证据的立意方案，并区分“来源事实”与“创作推断”:
- **方案 A (新派历史/大国重工)**: 工业摸底或国运崛起。
- **方案 B (都市脑洞/规则怪谈)**: 冷门职业+规则限制, 宜短剧化。
- **方案 C (极道横推/高武)**: 极致肉身流或寿元加点流。

### 5. 原创深度分析
针对推荐方案使用 **originality-audit** 规范进行原创性审计, 按 `templates/trending-analysis-template.md` 格式输出报告至 `analysis/trending-analysis.md`, 重点评估**情绪价值密度**与**爆款创新潜力**。
