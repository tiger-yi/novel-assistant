# 小说元数据生成指南 (Metadata Guide)

本规范根据 `world/outline.md` 生成书名、简介、标签和封面提示词，供 `生成小说元数据` pipeline 使用。平台约束与标签候选库在本文件内维护，不再依赖独立参考文件。

## 输入与输出

- **输入**: `world/outline.md`，必要时读取主角档案与写作风格。
- **准备输出**: `metadata/.staging/<transaction-id>/novel-metadata.md`。
- **正式输出**: `metadata/novel-metadata.md`。
- **写入边界**: Agent 只写准备输出；覆盖正式输出前必须获得用户确认，并由事务执行器发布。

## 执行流程

1. 读取大纲中的核心设定、金手指、主角、前三章卖点与长期冲突。
2. 按本文件的平台约束筛除不合规内容。
3. 从标签候选库选择一个主分类，并为主题、角色、情节三个维度各选择不超过两个副标签。
4. 生成五套完整方案；每套包含书名、简介、标签和封面提示词。
5. 将全部方案写入事务 staging，记录摘要与正式目标基线。
6. 用户确认覆盖且门禁通过后，由事务执行器发布正式文件。

## 平台约束

### 书名与主角名

- 书名不得使用特殊字符，最多 15 个字；包含英文时首字母必须大写。
- 主角名不得使用特殊字符，最多 5 个字。

### 作品简介

- 长度为 50-500 字。
- 突出前三章的核心冲突、爽点与悬念。
- 不得包含低俗、违法或以血腥暴力为卖点的内容。

### 标签选择

- 主分类必选且只能选择一个。
- 主题、角色、情节三个副标签维度各最多选择两个。
- 标签必须由作品已有设定支持，不得只为流量添加无正文依据的标签。

### 封面约束

- 成品必须包含清晰作品名称和作者笔名，并与作品风格一致。
- 建议尺寸为 600 x 800 像素，格式为 jpg、jpeg 或 png，文件不超过 5 MB。
- 中文小说封面应避免无意义英文字符；生成提示词只描述预留排版区域，不假设图像模型能正确生成中文文字。

## 标签候选库

### 主分类

- **都市类**: 都市高武、都市种田、都市日常、都市修真、都市脑洞、战神赘婿
- **玄幻/奇幻/仙侠类**: 传统玄幻、玄幻脑洞、西方奇幻、东方仙侠
- **历史/军事类**: 历史古代、历史脑洞、抗战谍战
- **悬疑类**: 悬疑灵异、悬疑脑洞
- **衍生类**: 男频衍生、动漫衍生
- **科幻/游戏类**: 科幻末世、游戏体育

### 主题标签

- **基础大类**: 玄幻、都市、历史、武侠、体育、奇幻仙侠、悬疑
- **世界背景**: 古代、架空、赛博朋克、克苏鲁、高武世界、异世大陆、东方玄幻、都市异能
- **核心元素**: 开局、第四天灾、规则怪谈、灵气复苏、末日求生、天灾、国运、断层、仕途、谍战、武将
- **衍生同人**: 衍生、综影视、综漫
- **时代背景**: 宋朝、清朝
- **叙事风格**: 第一人称

### 角色标签

- **情感设定**: 单女主、多女主、无女主
- **职业背景**: 特工、特种兵、神医、神探、游戏主播、学霸
- **地位权势**: 皇帝、女帝、宫廷侯爵、大佬、大小姐、校花、赘婿
- **人格特质**: 全能、天才、奶爸、反派、腹黑、扮猪吃虎

### 情节标签

- **穿越重生**: 穿越、重生、魂穿、双重生、穿书、灵魂互换
- **金手指**: 系统、空间、聊天群、黑科技、无敌、神豪、黑化、迪化
- **叙事流派**: 升级流、无限流、诸天万界、打脸、无脑爽、1v1、无后宫、惊悚游戏
- **核心任务**: 发家致富、高手下山、囤物资、捉鬼、捉妖、破案、推理、求生、争霸、科举、盗墓、鉴宝、乡村
- **职业技能**: 风水秘术、剑修、剑道、美食、直播、电竞、钓鱼、外卖、宠物

## 封面构思协议

生成提示词前输出简短决策摘要：意境、角色视觉特征、具象冲突符号、构图视角和排版预留。提示词结构为：

```text
[核心主体] + [视觉钩子] + [场景背景] + [构图视角] + [材质渲染] + [艺术风格] + [中文排版预留] + --ar 3:4
```

模型及版本参数可能变化，不在长期规范中硬编码；执行时由当前可用图像工具选择受支持参数。

## 输出结构

每套方案必须按同一字段输出：`方案 ID`、`书名`、`简介`、`主分类`、`主题标签`、`角色标签`、`情节标签`、`封面提示词`、`合规检查`。五套方案不得只替换书名，必须体现不同卖点定位。
