# 🖋️ ReAct 撰写正文规范 (V2.2 逻辑强化版)
**触发条件**：用户精确发出“开始撰写” 或 “写”时，**立即**启动此流程
当流程进入 **撰写阶段** 时，AI 必须严格按以下四个子步骤顺序执行，每步输出独立标题和指定格式内容，确保总字数控制在1500-2500字（正文占比85%以上）。

## 第零步：TODO (执行规划 - 任务清单化)
**核心目的**：从 World Bible 提取状态数据并生成执行核对清单。输出复选框清单，总输出≤150字。

*   **必备任务项**：
    0.  [ ] **数据对齐**：检索 `world/characters.toml` 获取主角实时境界、伤势；检索 `world/inventory.md` 获取可用道具。
    1.  [ ] **环境确认**：检索 `world/geography.md` 锁定当前地形、气候、光源锚点。
    2.  [ ] **信息边界**：明确各视角已知/未知信息，严防上帝视角。
    3.  [ ] **风格对齐**：提取 `world/outline.md` 情绪基调，结合用户指令（如“压抑”）预设策略。
    4.  [ ] **去 AI 味审计预警**：锁定本章禁用词库与总结性结尾风险点。
    5.  [ ] **结构锚点**：标记 Hook（钩子）、Climax（高潮）、Cliffhanger（悬念）的位置。
    6.  [ ] **数据变更预告**：列出需回写 Bible 的预期变更项（境界、道具消耗）。

## 第一步：Thought (深度构思 - 戏剧演化)
**核心目的**：将数据转化为具体的戏剧冲突逻辑，构建“虚拟片场”模型。输出 bullet point，总输出≤400字。

*   **风格对齐**：
    *   **全局基调**：读取 `world/outline.md` “题材赛道”（爽文/虐文）和“情绪闭环”，强制一致（爽文：短句≥60%、反击描写≥4处；虐文：环境渲染≥30%、心理独白≥5句）。
    *   **局部微调**：若用户输入有指令（如“压抑”），本章仅调整：心理权重+40%、语速降至长句占比≥50%。
*   **物理与生理锚点**：
    *   **干扰元素**：基于地理环境设定1项动态干扰（如：暴雨导致的视线模糊或地面湿滑）。
    *   **生理限制**：将 `characters.toml` 中的伤势/状态转化为具体的动作迟滞细节。
*   **心理动机与信息差**：
    *   **信息边界**：表格列出（角色|已知|未知）。
    *   **核心驱动**：1句本章核心动力（如：反派急于立功导致露出破绽）。
*   **剧情结构 (Pacing)**：
    *   **Hook**：开篇如何瞬间抓住读者？
    *   **Climax**：本章物理/情绪的最高冲突点。
    *   **Cliffhanger**：章末悬念锚点（留钩子）。
*   **节奏与基调**：高潮短句（≤10字/句，≥70%）；文戏长短交替（平均15字/句）。
*   **视觉节奏**：每段≤3行（手机屏高标准，240px）；关键动作独立段，首行缩进2空格。

## 第二步：Action (精准描写 - 沉浸叙事)
**核心目的**：执行正文撰写。物理反馈频率≥每200字1次，动作描写≥40%，对话占比≤20%。

*   **量化转换规则 (重要)**：
    *   禁止在正文出现任何数值、百分比或现代度量单位（除非系统流界面）。
    *   示例：❌“灵力剩余20%” -> ✅“丹田已近干涸，每一次提气都带出暗红的血丝”。
*   **物理受力与环境连续性**：
    *   **强制**：每冲突描写含环境反馈（如：碎石飞溅、气浪掀翻桌椅）。
    *   **连续性**：前段破坏物在后段必须复用（如：利用碎掉的门板做掩护）。
*   **动作与生理细节**：
    *   **Show Don't Tell**：严禁“感到/觉得/似乎”，替换为具体的生理颤动、肌肉紧绷或呼吸节奏变化。
*   **对话质感与人设**：
    *   **动作引导**：全对话配动作（❌“他说” -> ✅“刀落风啸：‘死！’”）。
    *   **潜台词**：主角话语精炼；配角话语需体现立场与利益。
*   **战力合规性**：
    *   遵 `world/power.md`，阶位差体现量化压制（如：威压导致的膝盖碎裂声、思维停滞）。
*   **正文输出**：统一输出至 `chapters/`，采用 `XXXX-章节标题.md` 格式，**必须写入磁盘**。

## 第三步：Observation (质量审计 - 编辑自查)
**核心目的**：执行逻辑与文风审计。若 Fail 必须在 Hotfix 中修正并**重写文件**。

*   **逻辑回溯**：
    1.  ✅/❌ **数据闭环**：核对 `world/inventory.md` 消耗；核对 `world/characters.toml` 伤势。
    2.  ✅/❌ **信息差**：确认无全知视角泄露。
*   **去 AI 味脱敏 (核心词库)**：
    1.  ✅/❌ **无总结结尾**：严禁“这一战，不仅是...更是...”、“...的开始”。
    2.  ✅/❌ **禁用词清理**：禁止出现：显然、显而易见、不得不说、交织、响彻云霄、缓缓、这一刻、紧接着、随之、旋即、璀璨夺目、命运齿轮、由此可见、预示、升华、不屈、余波、波动、似乎、仿佛。
*   **Hotfix & 更新**：
    1.  若审计 Fail：必须提供修正片段并**更新对应章节文件**。
    2.  **数据回写**：同步更新 `world/power.md`, `world/timeline.md`, `world/inventory.md`, `world/characters.toml`。
    3.  **大纲更新**：更新 `world/outline.md` 的进度表，确保后续 1-3 章规划存在。

## 写作禁忌 (强制负向规则，违者Hotfix)
1.  **总结结尾**：禁“奠定/预示/欲知后事”。
2.  **上帝视角**：禁“这不仅是战斗，更是信念碰撞”。
3.  **数据堆砌**：非面板视角，禁直接列敌数据。
4.  **滥用缓缓**：替换“睁眼/吐气”。
5.  **滥用这一刻**：禁“时间静止”等。
6.  **额外**：段落>3行重分；对话无动作标签重写；爽文逆转<3次重构。
