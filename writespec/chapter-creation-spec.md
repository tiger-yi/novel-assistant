# Phase 2: 沉浸撰写 (Drafting)

## 1. Thought (锚点锁定)
- **风格同步**: 严格对齐 `style-guide.md` 核心调性。
- **感官锚点**: 提取3项物理属性 (地形/天气/光源) + 1项动态干扰。
- **生理限制**: 锁定2-4项负担 (灵力/伤势/负重)。
- **视角锁定**: (角色|已知|未知) + 核心驱动力。
- **节奏规划**: 动作段落短句列阵，文戏长短交替。
- **强制输出**: 列出本章必植入的 **3个核心锚点 (Anchor Tags)**。

## 2. Action (精准描写)
- **锚点激活**: 前500字内必须通过描写激活 3 个核心锚点。
- **叙事策略**: 少对话多描写。严禁“他说/问道”，由动作开启对话。
- **环境重构**: 执行认知偏差滤镜，通过角色心理意象化环境 (详见 `style-guide` 叙事策略)。
- **非理性噪音**: 嵌入1个增强氛围的无关噪音 (蝉鸣/划痕声等)。
- **人性幽暗**: 角色动作体现微瑕 (自私/贪婪/迟疑)。
- **量化转换**: 严禁数值/百分比/现代单位。灵力20% -> 丹田干涸。
- **战斗结构**: 试探/布局 -> 底牌博弈 -> 终结/变数。
- **NO Meta**: 严禁提及“第X章/上文/此前”。禁用编号 (R16/C-12)，改用叙事称谓。
- **扩充策略**: 若字数不足，增加感官分层、环境回响或心理投射，严禁注水。
- **格式**: 输出至 `chapters/XXXX-标题.txt`。

## 3. Observation (质量审计)
1. **字数**: 运行 `python scripts/check_count.py` 确保 > 2000 字。
2. **符号**: 严禁 `【 】` `[ ]` `（ ）` `** **`。非对话严禁引号。
3. **去 AI 指纹**: 严格执行 `style-guide.md` 去 AI 化与颗粒度(指纹清理、拒绝总结、替换高频词)。
4. **比喻/情绪**: 封杀烂俗明喻 (像...一样)。情绪必须生理化、物件化。
5. **逻辑闭环**: 核对 `inventory.md` 消耗、伤势及信息差一致性。

# 🎯 伏笔管理 (Hook Management)
- **每章必收**: 优先 P0 > P1。
- **逾期预警**: 连续3章未推进 = ⚠️长期未回收；超过50章 = ❌危险。
- **新钩子**: 必须标注预期回收章节 (限本卷内)。
- **状态同步**: 回收后立即更新 `hooks.md` 并归档。
