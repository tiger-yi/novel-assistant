# World Bible 归档执行规范 (Archiving Rules)

## 1. 触发判定
- **卷终(Arc Complete)**: `outline.md` 中某卷标记为 `[已完成]`。
- **周期(Cycle)**: 每满 10 章进行一次归档触发；不足 10 章不归档。
- **强制(Manual)**: 用户输入 `归档世界观`。

## 2. 细则说明与主文件保留方案

归档的核心原则是：**主文件必须保持轻量化，但不能丢失历史索引。** 所有的归档操作完成后，必须在原主文件中留下对应的“归档链接”，以便 AI 追溯。

### 2.1 `outline.md` (剧情大纲)
- **归档对象**: 将已完成的“10 章块”或“完整卷”的详细章节规划表剪切至 `archive/outline_history.md`。
  - **注意**：每满 10 章触发归档，但这不等于一卷的结束（一卷可能有 15、27 章等）。因此，10 章块归档应以“章节区间”（如 `#第1-10章`）为锚点；若恰逢整卷结束，则可以“卷名”或“全卷区间”归档。
- **主文件保留方案**: 在详细章节规划表中，用一行归档记录替换原有的多行章节列表。包含“章节区间”、“(已归档)”、“一句话梗概（总结该段剧情核心事件）+ 存档链接”等信息。
- **主文件示例**:
  ```markdown
  | 章节 | 标题 | 核心事件 | 悬念钩子 | 状态 |
  | :--- | :--- | :--- | :--- | :--- |
  | **第1-10章** | **(已归档)** | > **核心梗概**：苏铭觉醒系统，完成平安公寓、乱葬岗送外卖、阳光小区404凶宅试睡等任务，获取原始资本，拒绝官方招揽后接取黑市猩红悬赏。<br>> 🔗 **详细章节规划已归档至**：[archive/outline_history.md#第1-10章](archive/outline_history.md) | - | ✅ 已完成 |
  ```

### 2.2 `hooks.md` (钩子与伏笔)
- **归档对象**:
  1. 将标记为 `✅ 已回收` 的钩子与伏笔条目迁移至 `archive/hooks_history.md`。
  2. 将 `情绪爆发点清单 (Emotional Peaks)` 中已发生的爆发点（根据“爆发章节”与当前已完成章节对比，如果当前已完成章节数 >= 爆发章节的最大值）迁移至 `archive/hooks_history.md`。
- **主文件保留方案**:
  1. 对于已回收的伏笔，仅保留“一句话结论”+“归档链接”。建议在文件末尾单独开辟一个 `## 4. 已回收伏笔索引` 区域。
  2. 对于已发生的爆发点，直接从清单中移除，并在清单底部添加统一的归档链接。
- **主文件示例**:
  ```markdown
  ## 1. 核心钩子 (The Big Hooks)
  | 章节 | 钩子描述 (Hook) | 预期回收章节 | 状态 | 备注 |
  | :--- | :--- | :--- | :--- | :--- |
  | 第11章 |  |  |  |  |
    > 🔗 **已回收钩子记录**：已归档至 [archive/hooks_history.md#已回收钩子记录](archive/hooks_history.md)
  
  ## 2. 伏笔埋设表 (The Seeds)

  | 埋设章节 | 伏笔描述 (Seed) | 表面掩盖解释 | 真实逻辑指向 (Fruit) | 状态 |
  | :--- | :--- | :--- | :--- | :--- |
  | 第11章 |  |  |  |  |
    > 🔗 **已回收伏笔记录**：已归档至 [archive/hooks_history.md#已回收伏笔记录](archive/hooks_history.md)

  ## 3. 情绪爆发点清单 (Emotional Peaks)
  | 序号 | 爆发章节 | 爆发点描述 | 情绪类型 | 爽感来源 |
  | :--- | :--- | :--- | :--- | :--- |
  | 3 | 第二卷中 | ... | ... | ... |
  > 🔗 **历史情绪爆发点记录**：已归档至 [archive/hooks_history.md#情绪爆发点记录](archive/hooks_history.md)
  ```

### 2.3 `chapter-summary.md` (章节摘要)
- **归档对象**: 每次触发归档时，迁移主文件中 **除最近 3 章以外** 的所有历史章节摘要至 `archive/chapter_summary_history.md`。
- **主文件保留方案 (上下文缓冲池)**: 为了在归档后仍保留近期上下文（防止写第11章时读不到前情），主文件必须**始终保留最新的 3 章摘要**作为缓冲池。
  - *例如*：写完第10章触发归档时，归档第 1-7 章，主文件保留 8-10 章。
  - *例如*：写完第20章触发归档时，主文件中有 8-20 章，则归档第 8-17 章，主文件保留 18-20 章。
  - 归档掉的章节块折叠为一个连贯的区间索引链接。
- **主文件示例** (假设刚写完第10章并完成归档):
  ```markdown
  ## 章节摘要
  > **第001章 - 第007章**: 🔗 已归档至 [archive/chapter_summary_history.md#第1-7章](archive/chapter_summary_history.md)

  ### 第008章：停尸房的午夜巡更
  （摘要内容...）

  ### 第009章：诈尸与狂暴镇压
  （摘要内容...）

  ### 第010章：血色规则的漏洞
  （摘要内容...）
  ```

### 2.4 `characters.md` (人物档案)
- **归档对象**: 将 `status` 为“已死亡”、“已消失”或“长期离场”的角色迁移至 `archive/characters_registry.md`（Markdown 文件；按人物 H3 标题“### 姓名”分节，字段采用表格呈现，锚点为角色名）。
- **主文件保留方案**: 在各势力或分类的末尾，或者在文件底部建立一个 `## 历史人物索引`，仅保留角色名、最终状态和归档链接，不保留任何数值与背景设定。
- **主文件示例**:
  ```markdown
  ## 历史人物索引 (已归档)
  - **李文正** [已死亡] - 青州边城城主 / 祭祀监潜伏者。 🔗 [查看档案](archive/characters_registry.md#李文正)
  ```

### 2.5 `timeline.md` (时间线)
- **归档对象**: 将当前卷之前的琐碎事件（非里程碑）迁移至 `archive/timeline_chronicles.md`。
- **主文件保留方案**: 主文件必须保留“里程碑事件（Milestones）”以维持大局观。将琐碎事件区块替换为归档链接。
- **主文件示例**:
  ```markdown
  ## 大历100年
  - **[里程碑]** 叶辰拜入青云宗。
  > 🔗 **大历100年琐碎事件记录**：已归档至 [archive/timeline_chronicles.md#大历100年](archive/timeline_chronicles.md)
  ```

### 2.6 `inventory.md` (道具与功法)
- **归档对象**: 将“已消耗”、“已损毁”、“已遗弃”的道具迁移至 `archive/inventory_logs.md`。
- **主文件保留方案**: 直接从主文件的活跃列表中移除。在文件底部增加一个 `## 历史消耗记录` 章节，提供统一的归档入口。
- **主文件示例**:
  ```markdown
  ## 历史消耗记录
  > 🔗 本主角一路走来所消耗的丹药、损毁的法宝及遗弃的低阶物品，请查阅：[archive/inventory_logs.md](archive/inventory_logs.md)
  ```

### 2.7 `geography.md` (地理与势力)
- **归档对象**: 将主角已离开且无后续伏笔（伏笔数=0）的旧地图详情迁移至 `archive/world_atlas.md`。
- **主文件保留方案**: 保留地图层级结构（比如某个大洲下的小国家），但将详细描述、特产、NPC列表全部删除，替换为一行状态说明与链接。
- **主文件示例**:
  ```markdown
  ### 青云宗 (东荒南域)
  > **状态**：主角已离开，当前无活跃伏笔。
  > 🔗 **详细区域志/历史设定**：已归档至 [archive/world_atlas.md#青云宗](archive/world_atlas.md)
  ```

## 3. 归档目录结构
```
world/archive/
├── outline_history.md      # 剧情大纲历史存档
├── hooks_history.md        # 钩子与伏笔回收历史
├── chapter_summary_history.md # 章节摘要历史
├── characters_registry.md  # 死亡/离场人物登记簿
├── timeline_chronicles.md  # 历史时间线长卷
├── inventory_logs.md       # 道具消耗/损毁记录
└── world_atlas.md          # 旧地图/已探索区域志
```
