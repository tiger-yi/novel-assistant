# 章节摘要模板
> **使用说明**：
> 1. 本模板用于记录每章的核心摘要，方便后续更新 World Bible。
> 2. **多个章节**：建议在章节之间使用 `---` 分割线以便于阅读。

## 1. 章节摘要列表 (归档后保留最近 3 章)

| 字段 | 填写内容 |
| --- | --- |
| 章节 ID | `CH-[四位章节号]` |
| 章节 | 第 [X] 章 |
| 标题 | [章节标题] |
| 时间/地点 | [时间点] / [地点/地图/势力] |
| 视角 | [主角/配角/旁观者] |
| 摘要正文 | [300-500 字浓缩叙述] |
| 关键事件 | [事件1]<br>[事件2]<br>[事件3] |
| 人物状态更新 | 主角：[境界/伤势/心境/关系变化]<br>重要角色：[姓名：状态变化] |
| 资源与消耗 | 消耗：[丹药/符箓/法宝/灵力]<br>新增/掉落：[战利品/情报/功法] |
| 伏笔与线索 | [ID] [描述]（状态：埋设/回收；关联：[相关章节]） |
| 逻辑校验 | 战力一致性：[通过/需修正]<br>时间/地理一致性：[通过/需修正] |
| 下一章承接 | 钩子：[悬念/冲突]<br>目标：[短期任务/推进方向] |
