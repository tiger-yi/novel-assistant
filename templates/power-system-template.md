## 第三部分：破境、代价与限制 (The Price)
*力量获取的风险与天花板。*

### 1. 破境机制 (The Mechanism)
- [ ] **资源堆叠 (Resource Accumulation)**：纯粹靠量变引起质变，如吞噬海量灵气/丹药强行冲关（凡人流）。
- [ ] **心境/顿悟 (Epiphany)**：需要解开心结、感悟红尘（化凡）或理解特定法则（唯心流）。
- [ ] **仪式/祭祀 (Ritual)**：需在特定天象（九星连珠）、特定地点（极阴之地）或献祭特定物品（至亲/生灵）方可晋升（诡秘/魔道）。
- [ ] **生死刺激 (Survival Instinct)**：只有在濒死状态下打破人体限制锁，向死而生（战斗狂/高武）。
- [ ] **斩断因果 (Severing Ties)**：必须斩断尘缘（杀妻证道？）或偿还所有恩怨才能飞升。

### 2. 失败惩罚 (The Penalty)
- [ ] **肉体崩坏 (Physical Backlash)**：经脉寸断、气血逆流、甚至直接爆体而亡（物理层面）。
- [ ] **境界跌落 (Regression)**：道基受损，修为倒退，且终身难以再寸进（根基层面）。
- [ ] **道化/畸变 (Daoization/Corruption)**：被法则同化变成石头/树木，或走火入魔沦为只知杀戮的怪物（精神/法则层面）。
- [ ] **天劫灰灰 (Tribulation)**：直接被天雷劈成劫灰，真灵不存，连轮回都进不去。

### 3. 上限与瓶颈 (The Ceiling)
- [ ] **世界锁 (World Lock)**：本位面能级过低，灵气不足以支撑更高境界（如化神即巅峰，再进必崩）。
- [ ] **血脉枷锁 (Bloodline Limit)**：祖上无强者，基因锁死了上限，除非换血/变异。
- [ ] **寿命大限 (Time Limit)**：在寿元耗尽前未能突破，气血衰败，只能坐化。
- [ ] **飞升机制 (Ascension)**：达到极限必须离开，否则被天地排斥（雷劈/强制传送至上界）。

### 4. 辅助手段 (The Catalyst)
- **外力**：丹药/灌顶/阵法。
- **机缘**：顿悟/天材地宝。
- **异象**：破境时是否会产生天地异象（祥瑞/灾厄）？

## 第七部分. ReAct 逻辑检查点 (Logic Checkpoints)

> **Thought (推理引导)**
> *   **平衡性**: 当前境界与上一境界的数值差距是否足以形成“碾压”？
> *   **稀缺性**: 突破所需资源（如“天基液”）在 geography.md 中是否有产出逻辑？
>
> **Action (生成规范)**
> *   必须明确每个境界的“特征描写”（如：筑基期可短暂滑翔，金丹期方可御剑）。
> *   定义“越级代价”：若要跨大境界杀敌，必须在 inventory.md 中有对应的代价记录（如：碎裂本命剑）。
>
> **Observation (一致性审计)**
> *   **[Audit]** 检索 characters.toml，检查是否有角色境界超出了当前定义的最高上限。
> *   **[Audit]** 检查正文战斗描写，是否出现了“练气期一拳打爆大乘期”的逻辑崩坏。
