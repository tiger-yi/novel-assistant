# 力量体系模板 (Power System)

## 第一部分：能量底层逻辑 (The Source)
*本模块决定了力量的“画风”与“真实感”。*

1.  **能量名称：** (例如：灵气、以太、气血、原力、疯狂值)
2.  **能量起源：**
    *   [ ] **内源型：** 诞生于生物肉体、神魂或基因。
    *   [ ] **外源型：** 宇宙射线、天地自然、维度裂隙。
    *   [ ] **赐予型：** 古神注视、神灵恩赐、血脉遗传。
3.  **能量性质：** (如：温和中性、暴戾混乱、具有污染性、需要等价交换)
4.  **交互方式：** (如何感知、吸纳、储存及转化效率)
5.  **能量阈值：** 环境中能量的密度（高魔/低魔/末法时代），是否存在“灵气复苏”或“枯竭”机制。

## 第三部分：破境机制与代价 (The Price)
*力量的获取从来不是免费的。*

1.  **破境必要条件：**
    *   [ ] **资源积累：** 能量达到饱和点。
    *   [ ] **心性感悟：** 对天道、规则或自我的认知突破。
    *   [ ] **外部契机：** 劫雷、祭祀仪式、血脉觉醒、特定位面。
2.  **失败风险：** (如：爆体而亡、境界跌落、神魂受损、永久畸变/失控)
3.  **天花板与离场：** 这个世界最强能容纳什么级别？达到上限后是“飞升”、“神降”还是“自我毁灭”？

---

## 第四部分：手段、技艺与媒介 (The Tools)
*能量如何被转化为实际的战斗力或生产力。*

1.  **内核功法：** 决定能量的产生效率、属性偏向、上限潜力。
2.  **外现技艺：** (术法、武技、诅咒、仪式)
3.  **外物依赖：**
    *   **媒介：** 符箓、法杖、阵盘、赛博植入体。
    *   **本命物：** 剑、法宝、共生妖兽、神灵肢体。
4.  **辅助体系：** 炼丹/制药、炼器/工业、驯兽/拼接、预测/占卜。

---

## 第五部分：社会生态与战力平衡 (The Impact)
*力量体系对文明结构的重塑。*

1.  **阶级分布：**
    *   **修凡比例：** (如 1:10000)
    *   **社会结构：** 宗门制、帝国制、教派制、还是松散的猎人组织？
2.  **资源分配：** 核心资源（灵矿、禁忌知识、长生药）掌握在谁手中？
3.  **越级挑战规则：**
    *   [ ] **绝对压制：** 高境界对低境界拥有绝对的意志/领域统摄。
    *   [ ] **智斗可能：** 依靠法宝、克制属性、禁忌知识、战术布局可逆袭。
4.  **社会评价：** 修炼者被视为“保护者”、“神灵代言人”、“剥削者”还是“行走的灾厄”？

## 第六部分：题材差异化核心自检 (Genre Check)

*   **[修仙/玄幻]**：是否设计了**“寿元”**压力？**“天劫”**是否与因果挂钩？
*   **[高武/肉身]**：能量消耗是否需要海量**“大药/进食”**？**“武道意志”**如何干涉现实？
*   **[克苏鲁/诡秘]**：**“理智值(San)”**如何量化？**“知识”**的毒性如何体现？**“扮演/仪式”**的规则是什么？
*   **[生存/低武]**：**“异化/畸变”**的进度条是否明确？**“绝望感”**是否源于无法弥补的战力差？

## 第七部分. ReAct 逻辑检查点 (Logic Checkpoints)

> **Thought (推理引导)**
> *   **平衡性**: 当前境界与上一境界的数值差距是否足以形成“碾压”？
> *   **稀缺性**: 突破所需资源（如“天基液”）在 geography.md 中是否有产出逻辑？
>
> **Action (生成规范)**
> *   必须明确每个境界的“特征描写”（如：筑基期可短暂滑翔，金丹期方可御剑）。
> *   定义“越级代价”：若要跨大境界杀敌，必须在 inventory.md 中有对应的代价记录（如：碎裂本命剑）。
>
> **Observation (一致性审计)**
> *   **[Audit]** 检索 characters.toml，检查是否有角色境界超出了当前定义的最高上限。
> *   **[Audit]** 检查正文战斗描写，是否出现了“练气期一拳打爆大乘期”的逻辑崩坏。
