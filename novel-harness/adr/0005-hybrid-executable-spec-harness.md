# 采用可程序化执行的混合规范架构

Novel Assistant 采用混合执行架构：Manifest 是命令路由、执行阶段和生效入口的机器权威，事务执行器是正式章节、World Bible 与归档写入的唯一入口；确定性约束由脚本判定，创作语义由 Agent 判断并提交结构化证据。事务、门禁、变更集和恢复点以 YAML 为唯一机器事实，人类可读说明由其渲染；这一设计增加了执行器与结构化证据的实现成本，换取可测试的触发、不可绕过的门禁、幂等提交和可恢复写入。

## Consequences

- 原始用户命令必须按 Manifest 中的触发词、别名或正则严格匹配，Agent 不得自行扩张正式写权限。
- 门禁结果统一为 `PASS`、`WARN`、`FAIL`、`NOT_APPLICABLE`；必需门禁或证据缺失时失败关闭。
- 手写流程图不再拥有执行语义，流程视图从 Manifest 生成。
- Markdown 规范负责解释领域语义，不承担运行时状态存储。
