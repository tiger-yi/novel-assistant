诡武真仙

【简介】
大武帝国，诡道复苏。这是一个崩坏的血色乱世。
朝廷腐朽，朱紫官袍下尽是蠕动的触手，为了维持统治不惜献祭万民；宗门冷酷，武者们为求力量，融合诡肢、生吞妖心，自诩神仙，实则人模鬼样。
妖魔割据山河，视人间为牧场；诡异阴影蔓延，不可名状的禁忌如天灾般吞噬城镇。
龙虎山第101代天师张黎明，携现代灵魂重生于此，睁眼便是全村死绝的灭村之祸。
在这个低武肉搏与疯狂异化并存的世界，传统道法不显，符箓威力百不存一。
张黎明被迫走上一条前所未有的禁忌之路：以大武武道淬炼肉身，以前世观想法镇守灵台。
“既然这世界的武道终点是疯癫，那我便观想九天神明，在这具肉壳里重塑神座！”
当其他武者因直视诡异而精神崩溃时，张黎明脑中观想“九天应元雷声普化天尊”，神目睁开，万邪皆避；
当朝廷权贵与妖魔共饮人血时，张黎明手持一柄玄铁桃木剑，将那虚伪的太平盛世斩个粉碎。
在这黑暗的四方角逐中，他是最疯的武者，也是唯一的真仙。
他要在这腐朽的帝国废墟上，用雷霆扫清寰宇，为这人间，杀出一片黎明。
“贫道张黎明，今日请诸位妖魔、漫天诡神、以及那高坐庙堂的满朝异类——赴死！”
【四大势力博弈】
朝廷（食人者）： 掌握权谋与秘密祭坛，以万民为血食，试图通过诡异力量延续皇权。
宗门（异化者）： 极致的低武暴力，为了突破肉身极限，不惜将身体改造成半人半妖的杀戮机器。
妖魔（掠夺者）： 纯粹的丛林法则，强悍的肉身与原始的本能，将人类领土割据为死亡禁区。
诡异（无解者）： 无法理解的规则性存在，红月降临、古神低语，是悬在所有人头顶的达摩克利斯之剑。
【核心卖点】
极致对撞： 正统道门智慧 vs 混乱无序的诡武乱世。
双修破局： 肉身打熬（低武横练）+ 神魂观想（前世神话诸神），不仅要杀得爽，更要杀得正气凛然。
杀伐果断： 面对视凡人为草芥的权贵与宗门，主角从不废话，唯有一剑一符一雷霆。
